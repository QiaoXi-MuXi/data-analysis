- 共享便携 Python 安装 `xlrd==2.0.2`（仅此一项新增依赖，已写入 `python/requirements.txt`），run.bat 用 `..\python\python.exe`，不回退系统 Python。
- 解析 16 份 MTS TestWorks `.xls`：Results 表 6 次压痕/文件；Test 001–006 的 P-h-t 曲线按段标记切分；RTF 只读方法/操作者溯源；`.mss` 原样保留不解析。

- 参考 Raman 的 `stack.xlsx` 做 `config.xlsx`：`fill_config.bat` 按 data 导入行并保留同名行的用户设置；「配置」表可设图例名称、样品编号、测点、是否参与、分组、备注；图例名称只写能量/条件，样品编号由程序自动附在后面，不再手写在括号里；`分组` 用于柱状图分簇，留空时从图例名称自动推断；「全局设置」表可设阈值和配对样品对；中英文表头、列顺序无关。`config.xlsx` 是唯一配置源；读取失败时依次回退 `_state/config_snapshot.json` 快照 → 按 data 自动生成默认配置，Excel 打开时提示读的是磁盘版本。
- 质控：载荷偏差、漂移、有效压痕数、E/H 稳健 z 离群、批内 COV、样品编号唯一性；异常只提示不改原始值。
- 文件内 Test 1..N 偏差分析与合并（参考 Ra 的组内均值+medoid 代表）：同一 xls 内各次压痕 E/H_COV ≤ Excel 阈值则只画一条代表曲线，偏差大则保留全部；只在文件内部聚合，不跨文件/不跨样品编号合并，E/H 数值不重算。
- 按样品编号分组统计；按测点配对配置指定的样品对；按 Excel `分组` 出柱状图（同组不同样品紧挨、组间留间隔、同一样品颜色一致）；按文件级 H 最大间隙识别双峰总体；配对用精确符号翻转置换，组间用固定种子 20000 次置换，不依赖 scipy。
- 输出 xlsx / csv / json / md / 32 张图：一张总图、一张全部压痕曲线叠放编号图（序号均匀排在顶部 + 引线连回曲线 + 图例分 4 列排在下方且只用 config 图例名称，画布高度按条数自适应，不分层）、文件内合并偏差图与合并曲线总图、每个样品编号一张、每个文件一张（含 P-h 曲线与逐次 E/H），另有分组柱状图、分组/配对/双峰/质控图与图片索引。
- 报告逻辑：按高/低硬度组分别给 COV，避免「最大 42.5% 却说全部低于 5%」的矛盾；双峰存在时跳过全体组间比较，避免混合分布误判。

本次数据结论（默认设置下，16 文件 / 96 次有效压痕）：

- 高硬度组（测点 1/2/9/10/11/12）：E ≈ 337.4 GPa，H ≈ 20.00 GPa，批内 COV 0.79%–2.06%。
- 低硬度组（测点 19/20）：E ≈ 240.5 GPa，H ≈ 5.73 GPa，批内 COV 36.5%–42.5%。
- H 双峰间隙 12.87 GPa（占全距 82.3%），测点/区域差异远大于同测点样品编号间的差异。
- 同测点 1100 vs 1210 的 ΔE/ΔH 均不显著（7 对，p=0.84 / 0.45）；限定高硬度测点后仍不显著（6 对，p=0.34 / 0.66）。
- 样品编号 1120 仅 1 个文件（15-1120-…-20），需人工核对；低硬度组 4 个文件均触发 COV 提示。
