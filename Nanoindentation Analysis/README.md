# 纳米压痕数据分析（Nanoindentation Analysis）

批量读取 MTS Nano Indenter / TestWorks 导出的 `.xls`，汇总弹性模量 E、硬度 H，
按样品编号与测点分组、配对比较，识别双峰总体与异常文件。
流程参考 Raman：`fill_config.bat` 先把数据导入 Excel，用户在 `config.xlsx` 里设置，再双击 `run.bat` 出图。

## 快速使用

| 项目 | 说明 |
|---|---|
| 输入 | `data/` 内 `*.xls`（TestWorks 导出，需含 `Results` 工作表）。本次实验 16 个文件已从 `2026-11-22 Batch #00001` 复制进来。 |
| 导入 | 双击 `fill_config.bat`：按 `data/` 现状生成/更新 `config.xlsx`，同名文件的用户设置会保留。 |
| 设置 | 打开 `config.xlsx`：在「配置」表设图例名称、样品编号、测点、是否参与、分组、备注；在「全局设置」表设阈值和 `输出格式`（默认 `png`）。`config.json` 只作为默认值兜底，一般不用改。 |
| 运行 | 双击本目录的 `run.bat`，全自动无交互，按设置生成 `out/figures/` 图组。 |
| 输出 | `out/`：`nano_results.xlsx`、`report.md`、`summary.json`、`indent_detail.csv`、`figures/`；默认仅 PNG。 |
| 环境检查 | 运行根目录 `check.bat`；使用共享 `../python/python.exe`，不回退系统 Python。 |

命令行（无人值守可设置 `$env:DATA_ANALYSIS_NO_PAUSE='1'`）：

```powershell
.\fill_config.bat                  # 先导入/刷新 Excel 配置表
.\run.bat                          # 按 config.xlsx 的设置分析并出图
.\run.bat --src '其他批次目录' --out '独立输出目录'
.\run.bat --config '另一张表.xlsx' # 指定配置表
.\run.bat --no-curves              # 跳过 P-h 曲线解析，只做 Results 统计
.\run.bat --no-plots               # 不生成图片
```

## Excel 配置表（config.xlsx）

参考 Raman 的 `stack.xlsx`：表头按名字识别，列顺序可调，中英文都认，括号里的 `(0/1)` 只是提示。

「配置」表（第一张工作表）：

| 列 | 含义 |
|---|---|
| `文件` | `data/` 里的 xls 文件名，必填；新增/删除文件后双击 `fill_config.bat` 刷新 |
| `图例名称` | 只填能量/条件名（如 `0.39J/cm²`），样品编号不用写；图上会自动显示为 `图例名称(样品编号)`，留空用文件名 |
| `样品编号` | 分组标签，默认从文件名第二段读取；可改成任意编号，如 `1100A` |
| `测点` | 配对键；同一测点下不同样品编号会配对比较，默认从文件名末段读取 |
| `参与(0/1)` | `0` = 本文件不参与分析和绘图；留空或 `1` = 参与 |
| `分组` | 柱状图分组名（如 `0.39J/cm²`）：同一分组内不同样品编号的柱子紧挨着，不同分组之间留间隔；留空时从图例名称自动去掉末尾样品编号得到（如 `0.39J/cm²(1100)` → `0.39J/cm²`），可手动覆盖 |
| `备注` | 只写给自己看，不参与计算 |

**配置兜底**：`run.bat` 只读 `config.xlsx` 这一份配置。若它正在 Excel 中打开，程序会提示"读到的是磁盘上已保存的版本"；若读取失败（被占用/损坏），依次回退到 `_state/config_snapshot.json`（上次成功读取的快照）→ 按 `data/` 自动生成的默认配置，保证分析不中断。`fill_config.bat` 检测到 Excel 占用时会直接提示先关闭，不做任何改动。

**结果表占用**：写入 `out/nano_results.xlsx` 前会先检查；若该表正被 Excel 打开，程序在清理 out 之前停止，提示保存并关闭后重新运行，返回退出码 4，上一轮 out 中的文件保持不变。

「全局设置」表：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `参考载荷_mN` | 30 | 标称载荷，用于偏差质控 |
| `载荷容差_pct` | 8 | 允许偏差 % |
| `漂移上限_nm_s` | 0.15 | 漂移修正绝对值上限 nm/s |
| `离群z阈值` | 3.5 | 稳健 z 分数（中位数/MAD）阈值 |
| `双峰最小间隙比` | 0.25 | 最大间隙占全距的比例，达到才认为有两簇 |
| `配对样品对` | `1100-1210` | 要比的两个样品编号；多对用分号隔开 |
| `绘图dpi` | 600 | 图片分辨率 |
| `输出格式` | `png` | 默认只输出 PNG；需要矢量稿时写 `png;pdf;svg`（可任意组合，至少一种） |
| `压痕合并_启用` | 1 | 同一文件内 Test 1..N 偏差小则合并为一条代表曲线（1开/0关） |
| `压痕合并_E偏差上限_pct` | 5 | 文件内各次压痕 E 的变异系数上限 % |
| `压痕合并_H偏差上限_pct` | 5 | 文件内各次压痕 H 的变异系数上限 % |
| `压痕合并_最小压痕数` | 3 | 一个文件至少几次有效压痕才考虑合并 |
| `能量色阶` | 内置 8 锚点 | 冷暖色轴，任意长度（如 `#08306B;#2C80BB;#C8CB94;#DD8438;#8C1A1A`）；按分组数在这条轴上等分取色，分组数变了不用改 |
| `端点边距` | 0.06 | 取色区间两端各留出的比例（0–0.35）；分组很少时不取到最暗的两端 |
| `样品配色` | 1100 蓝 / 1210 红 / 1120 橙 | 按样品编号指定颜色（`1100:#2f6fb5;1210:#d1495b`）；未列出的用默认 12 色板 |

留空即用默认值。表头别名示例：`文件/file`、`样品编号/sample`、`测点/point`、`参与/include`。

**配色怎么自适应**：能量色阶是一条连续色轴，分组有几个就在轴上等分取几个点（2 组取两端、12 组取 12 个等分点），色阶长度和分组数互不影响；样品颜色单独配置，默认 12 色板 + 标记/线型二级循环，超过 6 个样品也不会撞色。改颜色只需要动「全局设置」，不用改代码。`config.json` 里的 `绘图.能量色阶/端点边距/样品配色` 是同一组参数的兜底默认值，旧版的 `绘图.配色` 仍按样品颜色识别。

## 输入文件与命名

仪器每次导出三个同名文件：`.mss`（原始 OLE 二进制）、`.xls`（结果表 + 原始曲线）、`.rtf`（文字报告）。
**本模块只读 `.xls`**：E/H 取 `Results` 表的 `Modulus/Hardness At Max Load`（仪器已用标定面积函数算好）；
`Test 001`…`Test 006` 工作表提供载荷-位移-时间序列，用于残余深度、保载蠕变、卸载刚度和 pop-in 线索。
`.rtf` 仅提取方法与操作者用于溯源，`.mss` 原文件保留不解析。

文件名参考格式：`序号-样品编号-标称载荷-加载速率-保载时间-测点`

```
1-1100-30mN-5mns-5s-1.xls
│   │    │    │    └─ 测点编号 1（配对键：同测点不同样品编号）
│   │    │    └────── 加载速率 5 mN/s
│   │    └─────────── 标称载荷 30 mN
│   └──────────────── 样品编号 1100（不是温度，仅作为分组标签）
└──────────────────── 文件序号
```

第二段只是**样品/条件编号**，没有温度含义。命名解析失败的文件不会中断整批，只打上标记继续分析；
也可以在 Excel 表里直接改正样品编号。

## 算法流程

1. **导入**：优先按文件名开头的序号排序扫描 `*.xls`，无法解析序号时按自然顺序（`2-1` 在 `10-1` 前）兜底；读 `config.xlsx`，应用图例/样品编号/测点/参与开关与全局阈值。
2. **读取**：`Results` 表逐行取 E、H、漂移、最大深度、最大载荷、针尖与面积系数；每个 `Test NNN` 表按段标记（加载/保载/卸载/热漂移）切分曲线。
3. **质控**：标称载荷偏差、漂移速率、有效压痕数、批内 E/H 稳健离群（中位数/MAD，z>阈值）、样品编号唯一性。异常写进报告，不静默改数据。
4. **文件内压痕合并**：同一个 xls 里的 Test 1..N 先做偏差分析（各次压痕 E/H 的 COV 与相对均值最大偏差）；两项 COV 都不超过上限时判为内部一致，多条 P-h 曲线合并为一条代表曲线（medoid = E/H 联合最接近文件均值的那次压痕），偏差大的文件保留全部曲线。**只改曲线聚合方式，不重算 E/H**。
5. **分组**：按样品编号汇总压痕级均值±SD、COV；按测点配对指定样品对的 E/H 差值；另按 Excel `分组` 列出柱状图，同组不同样品紧挨、组间留间隔、同一样品颜色一致。合并与分组是两个独立维度——合并在文件内部，分组在不同文件之间，不会把不同测点/不同样品编号混成一份。
6. **双峰识别**：按文件级 H 均值找最大间隙，间隙占全距比例超过阈值时切成高/低硬度两组，避免把两类材料平均成一个没有意义的数。
7. **统计检验**：配对差值用精确符号翻转置换检验（≤20 对枚举全部 2ⁿ）；独立组用固定种子的 20000 次蒙特卡洛置换检验。不依赖 scipy。
8. **出图**：按 `out/figures/` 输出 Fig1–Fig5、FigS1、`merged_curves`、`grouped_bar` 以及每个源文件一张单文件三联图（数量随输入文件数）；默认仅 PNG，格式由「全局设置」的 `输出格式` 控制。
9. **结论**：自动生成 `report.md`，含文件内压痕合并判定、分组统计、双峰发现、配对检验、数据质量和方法边界。

绝对 E/H 不重新用 P-h 曲线计算——仪器的面积函数标定更可靠；曲线只用于机理性指标。

## 本次实验（2026-11-22 Batch #00001）结论摘要

16 文件 / 96 次有效压痕。完整数值以 `out/report.md` 为准：

- 高硬度组（测点 1、2、9–12，12 文件）：E ≈ 337 GPa，H ≈ 20.0 GPa，批内 COV 0.8%–2.1%，重复性良好。
- 低硬度组（测点 19、20，4 文件）：E ≈ 240 GPa，H ≈ 5.7 GPa，批内 COV 36%–43%，离散显著，只宜半定量参考。
- 两组 H 相差 12.9 GPa（占全距 82%），远大于同测点样品编号间的差异；不能把全部压痕混在一起只报一个平均值。
- 同测点 1100 vs 1210：ΔE、ΔH 均不显著（p>0.05）；仅取高硬度测点结论相同。
- 样品编号 1120 只出现 1 个文件，建议核对其余设置或文件名。

> 双峰对应不同材料相/区域还是工艺异常，需结合测点位置与样品形貌判断；本报告不做材料归属推断。

## 方法边界

- E/H 的绝对值受针尖面积函数标定影响；本模块只汇总仪器结果，不重算绝对值。
- 显著性基于置换检验，不改变原始数据；p 值只说明这批数据的差异是否可能由随机波动产生。
- 低硬度组的大 COV 提示采样位置敏感（界面、多孔、膜层破裂等均可能），单次均值不可当材料常数。
- pop-in 检测是加载段位移突增的经验阈值，需人工复核曲线，不作为结论性证据。
