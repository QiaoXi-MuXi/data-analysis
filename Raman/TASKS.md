# Raman 基准对比分析模式实施任务（2026-11-24）

> 当前状态：**P0 已实施并完成隔离验收**。单谱、堆叠模式保持原输出；基准对比已接入 CLI 与桌面 GUI。`compare.xlsx` 目前仍是空模板，尚未用用户真实基准谱/样品谱运行。
>
> 实施目标：在保留现有“单谱”和“堆叠对比”模式的基础上，新增独立的“基准对比分析”模式，用一个基准拉曼谱对多个样品谱做可复核的峰级与全谱比较，并接入命令行和现有桌面 GUI。

## 1. 背景与现有不足

### 1.1 现有实现

- `Raman/plot_raman.py`：目前同时承担 TXT 读取、峰检测、高斯峰位拟合、绘图、Excel 配置读取、命令行调度与结果写出。
- 单谱模式：逐文件出图并输出 `peaks.csv`，支持波数区间、峰高阈值、`XSHIFT` 和激光线假峰排除。
- 堆叠模式：由 `stack.xlsx` 控制多条谱的顺序、归一化、纵向偏移和峰位标注，但本质仍是**视觉叠图**，没有基准对象和定量比较结果。
- 可复用算法：`smooth`、`local_maxima`、`baseline_under`、`gauss_fit`、`peak_center`、`noise_sigma`、`auto_threshold`、`find_peaks`、`save_figure`、`safe_stem`。
- 桌面端调用链：`gui/model.py` 构造命令，`gui/documents.py` 管理配置和校验，`gui/runs.py` 冻结配置、记录输入摘要并归档独立运行目录，`gui/app.py` / `gui/editor.py` 提供界面。

### 1.2 本次要补足的能力

1. 不能指定一条基准谱并批量比较多个样品。
2. 没有基准峰与样品峰的一一匹配，不能区分匹配峰、缺失峰和新增峰。
3. 没有峰位偏差、匹配率、全谱相关性等结构化指标。
4. 现有 `MAX_LABELS` 是绘图标注上限，定量比较不能因此只分析最高的 10 个峰。
5. 没有逐样品基准叠加图、残差图和批量峰位偏差图。
6. 没有保存基准文件、样品文件、阈值和参数的完整追溯信息。
7. GUI 目前只有样本配置（堆叠）和目录（单谱）两种 Raman 运行方式，需要新增明确的第三种模式。

## 2. 范围与产品决策

### 2.1 P0 必须完成

- 一次运行指定**一个基准谱 + 一个或多个样品谱**。
- 基准和样品使用相同波数窗口、相同峰检测口径；每条谱可单独确定峰高阈值。
- 输出全部峰的匹配明细、样品汇总指标、基准峰表、逐样品比较图和运行清单。
- 支持不同波数采样网格；仅在共同范围内线性插值，不外推。
- 命令行通过 `run.bat --compare compare.xlsx` 使用；GUI 增加“基准对比”模式。
- 保持既有单谱、堆叠模式的默认入口、科学算法和输出风格不变。

### 2.2 明确不在 P0 内

以下功能不得挤入本次实现，也不得为了完成它们改变既定口径：

- 多基准谱库自动检索、物相识别或“最可能材料”排名。
- 自动基线校正、自动峰对齐、自动拉伸/压缩波数轴。
- 根据峰强比直接推算浓度、含量或绝对强度结论。
- 把多个指标合成为未经验证的“相似度百分比”“合格率”或“鉴定结论”。
- 人工基准峰列表、批量热图、多参考模板管理（可列为后续独立需求）。
- 新增 SciPy 等科学计算依赖。P0 只使用现有便携 Python 中的 numpy、matplotlib、openpyxl 和标准库。

### 2.3 科学表达边界

- “匹配”只表示峰位差未超过用户容差，不代表已经确认同一物相。
- 全谱 Pearson 相关系数只是当前窗口和处理口径下的曲线相似性指标，不是物相鉴定概率。
- 原始 `H` 沿用现有定义，只适合同批数据内描述；跨谱强度比必须注明受采集条件和归一化影响。
- 不做自动峰位对齐，因为对齐会抹掉本次需要测量的峰位偏移。全局人工校正量必须同时作用于基准和样品。

## 3. 使用方式与配置规格

### 3.1 命令行入口

新增互斥参数 `--compare`：

```powershell
.\run.bat --compare .\compare.xlsx
& ..\python\python.exe -B .\plot_raman.py --compare .\compare.xlsx
& ..\python\python.exe -B .\plot_raman.py --compare .\compare.xlsx --src .\data --out '<隔离结果目录>'
```

固定规则：

- `--compare` 与 `--stack` 同时出现时返回参数错误，退出码 2。
- 无 `--compare`、无 `--stack` 时完全沿用既有单谱逻辑。
- 无参数双击 `run.bat` 的既有行为不变，不因存在 `compare.xlsx` 而自动切换模式。
- 不新增第二个 Raman 分析启动 BAT；`run.bat` 已能原样转发 CLI 参数。
- `--xmin/--xmax` 若显式提供则覆盖工作簿区间；单边覆盖必须报错。
- `--out` 沿用现有“结果目录”语义。清理任何旧文件之前必须完成配置、基准和全部输入路径的安全性检查。

### 3.2 `compare.xlsx` 工作簿

新增独立配置，**不要向 `stack.xlsx` 追加列**，避免破坏 `_check_columns.py`、旧配置和既有 GUI 导入。

工作簿包含 `样品`、`参数`、`说明` 三张表，第一张固定为 `样品`。

#### `样品` 表

| 列 | 必填 | 空白默认 | 说明 |
|---|---:|---|---|
| `文件` | 是 | 无 | 样品 TXT；相对路径基于 `--src`，可省略 `.txt`，绝对路径按现有 `resolve_src` 规则处理 |
| `图例名称` | 否 | 文件主名 | 图表和结果表中的样品名称；`|` 的换行规则仅用于图例，不写进 CSV 字段 |
| `启用(0/1)` | 否 | 1 | 0 表示保留配置但不参与本次分析 |
| `峰高阈值` | 否 | 自动阈值 | 原始 counts；留空时在该样品的共同分析窗口内调用现有 `auto_threshold` |
| `标注峰位(0/1)` | 否 | 1 | 只控制绘图标注密度，不得裁剪导出的分析峰 |

至少一条启用样品。空行和首单元格以 `#` 开头的行跳过。支持既有风格的英文别名：`file`、`label`、`enabled`、`height`、`peaks`。

#### `参数` 表

三列固定为 `参数`、`值`、`说明`。读取前两张列作为键值，第三列只作备注。

| 参数 | 必填 | 默认值 | 约束与含义 |
|---|---:|---:|---|
| `基准文件` | 是 | 无 | 一个两列 TXT；绝对路径，或相对于 `compare.xlsx` 所在目录，推荐 `reference/xxx.txt` |
| `基准名称` | 否 | 基准文件主名 | 图例和清单中的名称 |
| `基准峰高阈值` | 否 | 自动阈值 | 原始 counts；在共同分析窗口内计算 |
| `区间下限` / `区间上限` | 否 | 共同交集 | 必须同时填写或同时留空，且下限小于上限 |
| `匹配容差` | 否 | 10 | 有限正数，单位 cm⁻¹；边界 `abs(delta) <= 容差` 视为可匹配 |
| `归一化(0/1)` | 否 | 1 | 比较图和残差图是否逐谱缩放到共同窗口内的 0–1；不改变原始 H 的检测口径 |
| `峰位校正` | 否 | 0 | 有限数值，同时加到基准与所有样品波数，等价于现有 `XSHIFT` |
| `激光线排除半宽` | 否 | 50 | 有限非负数，0 表示关闭；以校正后的激光线位置为中心 |

规则：

- 重复参数、无法识别的参数、非法布尔值、非有限数值均明确报错，不静默忽略。
- 未显式填写的默认值必须写入 `compare_run.json`，保证结果可复核。
- `说明` 表给出路径、阈值、容差、输出和科学解释边界，不参与计算。
- `_make_compare_xlsx.py` 负责生成模板；生成脚本不得覆盖用户已有 `compare.xlsx`，除非用户显式指定一个新路径。

### 3.3 GUI 使用方式

- Raman 页面新增第三项“基准对比”，既有“样本配置”（堆叠）和“目录”（单谱）名称与默认选择不变。

## 4. 分析算法与统一口径

建议把新增科学逻辑放在独立模块，避免继续膨胀 `plot_raman.py`：

- `raman_compare.py`：数据校验、共同窗口、峰值检测适配、插值、匹配、指标。
- `compare_config.py`：工作簿读取、参数校验、默认值解析。
- `compare_report.py`：CSV/JSON 和比较图输出。

### 4.1 数据读取与窗口

1. TXT 继续使用前两列：波数、强度；支持 `#` 注释。
2. 比较模式要求波数和强度全部为有限数。允许严格升序或严格降序；降序时同时反转两列。
3. 非单调、重复波数、少于两列、空文件必须给出含文件名的错误，不静默排序、去重或平均。
4. 人工全局校正同时应用于基准和样品；窗口语义与现有单谱 `XSHIFT` 一致。
5. 未指定窗口时，对所有“基准 + 启用样品”的可用范围求交集：

   `lo = max(各谱最小波数)`，`hi = min(各谱最大波数)`。

6. 显式窗口超出任一谱范围时不得外推，指出该文件及其有效范围。共同窗口内基准网格少于 8 点时终止本次运行。
7. 配置错误、基准读取失败、无共同窗口、输入位于将被清理的输出目录等全局错误，必须在清理输出前退出。

### 4.2 峰检测

- 平滑、局部极大、`H = I_max - I_baseline`、高斯 + 线性基线峰位拟合、激光线排除全部复用现有实现，避免比较结果与单谱模式出现两套口径。
- 显式阈值优先；空白阈值使用 `auto_threshold`，并把每条谱最终使用的阈值写入汇总表和运行清单。
- 峰检测使用共同窗口内的**原始强度**，归一化只用于显示及额外的高度比字段。
- 将“检测全部峰”和“图上最多标几个峰”分开。可以给现有 `find_peaks` 增加可选的无截断方式，但旧调用默认行为必须逐峰保持一致。
- 比较明细不得受 `MAX_LABELS`、逐样品图标注数量或 `peaks=0` 影响。

### 4.3 一一峰匹配

设基准峰和某一样品峰均按波数升序排列。仅允许 `abs(sample_center - reference_center) <= tolerance` 的峰组成候选对。

采用保持波数顺序的动态规划或等价确定性算法，目标按以下优先级求解：

1. 最大化匹配对数。
2. 在匹配对数相同的方案中最小化所有匹配对的 `abs(delta)` 之和。
3. 仍相同时按基准峰序号、样品峰序号字典序选择，保证重复运行结果一致。

输出：

- 已匹配基准峰：`matched`。
- 未匹配基准峰：`missing`。
- 未匹配样品峰：`new`。

禁止简单按最近距离全局贪心，因为它可能减少总匹配数；禁止一个基准峰匹配多个样品峰或反之。

### 4.4 全谱相关性

- 使用共同窗口内基准谱的波数点作为公共网格；将每条样品谱线性插值到该网格，不外推。
- Pearson 在插值后的原始强度上计算，因其对线性缩放不变，与绘图是否归一化无关：

\[
r=\frac{\sum_k(x_k-\bar{x})(y_k-\bar{y})}{\sqrt{\sum_k(x_k-\bar{x})^2\sum_k(y_k-\bar{y})^2}}
\]

其中 `x` 为基准强度向量，`y` 为样品强度向量。

- 任一向量方差为 0、点数不足或出现非有限值时，`pearson_r` 留空并写明原因，不得写成 0。
- 不同样品必须使用同一公共窗口和同一基准网格，避免各自选择区间导致相关系数不可横向比较。

### 4.5 峰级与汇总指标

对匹配峰定义：

\[
\Delta\nu=\nu_{sample}-\nu_{reference}
\]

- `match_rate = matched_peaks / reference_peaks`，取值 0–1；基准峰数为 0 时留空。
- `mean_delta_cm-1`：匹配峰 `delta` 的带符号平均值。
- `mae_delta_cm-1`：匹配峰 `abs(delta)` 的平均值。
- `max_abs_delta_cm-1`：匹配峰最大绝对偏差。
- `rmse_delta_cm-1`：匹配峰偏差平方均值的平方根。
- 没有匹配峰时，上述四项均留空，不写 0。
- `H_ratio = sample_H_counts / reference_H_counts`，分母为 0 时留空。
- 若共同窗口强度跨度 `D = max(I)-min(I) > 0`，另算 `H_norm = H / D` 和 `H_norm_ratio`；`D <= 0` 时相关归一化字段留空并警告。
- 缺失峰和新增峰没有对应峰位或 H 的字段一律留空，不得补 0。

### 4.6 单样品失败与退出码

- 基准或全局配置失败：退出 1，不生成看似完整的批次结果。
- 某样品缺失、读取失败、窗口内点数不足、常量谱等：该样品在汇总表标记 `failed` 并记录原因，继续处理其他样品。
- 至少一个样品成功且部分样品失败或部分结果写图失败：退出 2。
- 全部成功：退出 0；没有任何样品成功：退出 1。
- 命令行日志逐样品打印最终阈值、基准峰数、匹配/缺失/新增数和结果路径；错误信息必须包含具体文件。

## 5. 输出规格

比较模式在 `--out` 指定的结果目录生成以下文件。GUI 仍写入每次独立运行的 `results` 目录。

### 5.1 `compare_reference_peaks.csv`

每个检测到的基准峰一行，不受绘图标注上限影响：

`reference_peak_id, peak_cm-1, H_counts, I_max, I_baseline, threshold_counts`

- `reference_peak_id` 使用按波数升序的 `R1、R2...`，同一批输出中作为稳定关联键。

### 5.2 `compare_peaks.csv`

每个“匹配/缺失/新增”事件一行，按样品配置顺序、基准峰位和样品峰位稳定排序：

`file, label, reference_peak_id, reference_peak_cm-1, sample_peak_cm-1, status, delta_cm-1, abs_delta_cm-1, tolerance_cm-1, reference_H_counts, sample_H_counts, H_ratio, reference_H_norm, sample_H_norm, H_norm_ratio`

- `status` 只使用 `matched / missing / new`。
- 缺失峰保留基准字段，样品字段留空；新增峰保留样品字段，基准字段留空。
- CSV 使用 `utf-8-sig`；数值格式统一，不能因区域设置改变小数点。

### 5.3 `compare_summary.csv`

每条启用样品恰好一行，包括失败样品：

`file, label, status, reference_peaks, matched_peaks, missing_peaks, new_peaks, match_rate, mean_delta_cm-1, mae_delta_cm-1, max_abs_delta_cm-1, rmse_delta_cm-1, pearson_r, sample_threshold_counts, points, xmin_cm-1, xmax_cm-1, message`

- `status` 使用 `success / failed`；`message` 记录失败原因或非致命警告，无内容则留空。
- 失败样品的计数和指标留空，不能写成全部 0。

### 5.4 图像

1. 每条成功样品输出 `compare_<safe_stem>.png`：
   - 上图：基准与样品同轴叠加；基准使用固定黑色或深蓝粗线，样品使用醒目对比色。
   - 标注匹配峰及基准峰编号；缺失基准峰用明确符号表示，不能用“没画标签”代替。
   - 下图：同窗口残差 `sample - reference` 和零线；归一化开启时两者先各自归一化，纵轴标 `norm. diff.`，关闭时标 `CCD cts diff.`。
   - 图上只减少标注密度，不改变计算结果；图名冲突必须提前报错或确定性去重，不能覆盖。
2. 批量输出 `compare_shift.png`：
   - 横轴基准峰位，纵轴 `delta_cm-1`，不同样品分色。
   - 画出 `+tolerance`、0、`-tolerance` 三条参考线；缺失峰不以 0 偏差绘制。
   - 若全批没有匹配峰，可不生成此图，但必须在清单和日志说明。

### 5.5 `compare_run.json`

至少保存：

- `schema_version`、模式、创建时间、本次状态。
- 配置文件、基准和全部启用样品的绝对路径、大小、SHA256。
- 用户显式参数和全部默认参数的解析结果、共同窗口、公共网格点数。
- 算法名称及关键常量（平滑、拟合窗口、峰合并距离、零峰排除、匹配容差）。
- 每条谱最终阈值、输出文件清单、警告与失败原因。
- GUI 自身的 `project.json`、`config.xlsx` 和 `run.json` 归档机制继续保留，不能用 `compare_run.json` 替代。

3. 不做自动波数拉伸、逐谱峰位对齐或隐式基线校正；归一化只用于显示，不能改变原始峰高和定量结果。
4. 所有定量比较使用同一基准、同一共同窗口和公共网格，不外推。缺失峰、无匹配、失败扫描留空，绝不补 0。
5. 不用红绿颜色把点直接判成“合格/不合格”，不合成未经验证的总相似度、物相概率或浓度结论。
6. 同点均值或点间离散只作描述，不给未经验证的显著性、置信区间或质量判定。

## C. 显示代表谱与计算口径

### C1. 显示代表谱

配置项“代表谱”支持：

- mean（默认）：同点成功扫描在共同公共网格线性插值后逐点算术平均。
- first：使用最小扫描号，页内仍显示其它扫描。
- none：不画代表粗线，只画原始扫描。

选择 mean 时必须满足：

- 标题/图注写 display mean, n=实际成功数/期望数，并保留三条原始细线。
- 平均只用于总览和跨组显示；不得覆盖原始 TXT，不得把均值当成一次新测量。
- 定量表优先保留逐扫描结果。若另算代表谱指标，字段 spectrum_kind=display_mean 明确区分，不能与逐扫描统计混合。
- 仅一条成功扫描时可以显示该条，但标 n=1/3；全部失败则该点面板显示 No valid spectrum，不得生成空白但看似正常的谱。
- 各扫描共同窗口不足或采样网格无效时沿用现有 compare 规则失败，不外推、不静默排序或去重。

### C2. 归一化与坐标

- 总览默认“归一化=1”，所有图注写 normalized for display；需要比较原始强度时统一切换，不在同图混用两种尺度。
- 同组总览所有面板共享相同横轴；1100 与 1210 总览也共享横轴，便于逐格对照。
- 每格纵轴只作形状浏览，隐藏无意义的堆叠数值；单点和差值页按实际内容标 CCD cts、norm. 或 norm. diff.。
- 峰检测继续使用共同窗口原始强度；图中少标峰不影响 CSV 全峰输出。
- 默认不自动按“异常程度”排序，以免把探索性指标变成质量判定。点号顺序始终是主顺序，可另提供不改变源数据的指标排序表。

### C3. 点级聚合与状态

点级表至少区分：

- expected_scans=3、valid_scans、failed_scans、missing_scans。
- 逐扫描指标的有效值数量；仅在有有效匹配时计算 delta 的均值、标准差、最小/最大绝对值。
- n=1 时样本标准差留空；零有效值时所有指标留空并写原因。
- status 只表达数据状态，如 complete / partial / failed，不表达样品质量。
- 每个聚合值都能回链到具体组、点、扫描、基准和源文件；禁止只保存均值而丢掉明细。

## I. 拼图模式实施记录（2026-11-24）

### I1. 需求与定位

一张图同时给出“打谱的位置”和“那个位置打出来的谱”：上方实物显微照片，下方该样品各测量位置的光谱。它与堆叠图的分工是：堆叠图跨**样品**比，拼图在**一个样品内部**把照片和位置谱绑在一起，不跨样品混画。

### I2. 输入发现

自动扫描（`--montage` 不带值）只认这一套命名，避免把已经出好的谱图误当照片：

- 实物图 `<组名>-1-1.png`：`1-1-1.png` → 组 `1`，`20-1-1.png` → 组 `20`
- 光谱 `<组名>-<序号>.txt`：`1-1.txt / 1-2.txt / 1-3.txt`
- 组名前缀整段匹配（`1-` 不吃 `10-1`，`2-` 不吃 `20-2`），与自然排序一致
- 谱图 `1-1.png` 以 `-1` 结尾、不以 `-1-1` 结尾，因此不会被当成实物图
- 一组缺位置 1 的谱（如 20 只有 20-2/20-3）仍成组；完全没有实物图的组跳过并提示

配置表 `montage.xlsx`（可选）一行一条光谱，同「组名」合并成一张拼图，实物图每组写一次；组名留空按文件主名推。校验口径与 `stack.xlsx` 一致（表头按名字找列、`(0/1)` 提示可省、空行与 `#` 行跳过、同组归一化必须一致），另加：实物图/光谱必须存在、颜色必须是 matplotlib 认得的写法、同组区间上下限冲突报错。模板由 `_make_montage_xlsx.py` 生成，`--from-src` 可按目录预填。

### I3. 版式与科学口径

- 画布仍 2048 px 宽；上方照片按原始长宽比缩放，**左右边缘与下方谱图区等宽**（照片不再比谱图窄、两侧不留白），高度随照片比例，只有极端竖长照片才缩窄；外框与谱图同一套细黑线，避免照片被拉伸
- 下方一条坐标轴，各位置按基线纵向错开；位置 1/2/3 默认红/绿/蓝，对应显微照片上常见的三色十字标记，颜色可在表里改
- 图例横排在坐标轴框外上方：这批数据右端有荧光背景和小峰，图例搁框里必与峰位标签相叠
- 峰位、`H = I_max - I_baseline`、高斯 + 线性基线拟合、激光线排除全部复用单谱实现，不引入第二套口径；每条谱最多标最高的 6 个峰，标签过密时错层 4 档（`label_peaks(..., levels=4)`，默认 3 档，旧图不变）
- 上方留白按 `max(0.12×span, 5.6×一行字高)` 计算，保证贴顶那条谱往上的错层标签不被边框切掉
- 阈值：配置行留空时按这条谱自适应 `max(5.5σ, 1.1%×H_max)`，与 `stack.xlsx` 留空时同口径；要全批统一阈值就在行里填数或用命令行 `--height`（2026-11-25 由固定 5 改为自适应，原因见 K 节）
- 纵刻度数字是错开后的位置，只用于看单条谱自身强弱；跨位置比峰高用 `montage_peaks.csv` 的 `H`，README 已写明

## K. 假峰治理：噪声地板、半高宽判据与滤光片截止边（2026-11-25）

用户反馈“Raman 峰位强度有些问题，怀疑某些地方出现了假峰”。复核 124 条实测谱后确认假峰分三类，逐类定位到判据而不是数据：

### K1. 诊断证据（改前口径：thr = max(2.5σ, 1.1%×H_max)，激光线 ±50，无宽度判据）

- 41 个位置 × 3 次重复共 604 个标签：**221 个落在 1200 cm-1 以上**——该区间 124 条谱里没有任何真实带，只有荧光背景和噪声；**282 个在同一位置的重复谱里只出现一两次**（真带在三次重复里必然同时出现），完全对不上的 210 个。
- 单谱最多 10 个标签（`MAX_LABELS` 截到上限），弱信号谱（1100 的 14~20、1210 全部，H_max 84-250、σ 1.0-1.7）几乎条条爆满；例如 1100\16-2 标出 1461.89、1761.20、2095.77、2261.39、2520.47、2633.64、2702.51、2926.61，全是噪声鼓包。
- **76 cm-1 处的“峰”是边通滤光片截止边**，不是材料信号：这批谱从 55 cm-1 陡升到 76 cm-1 再缓慢衰减（y 460 → 665 → 600），`local_maxima` 把台阶顶当成局部极大，H 可达 35-96 counts，比 762 cm-1 的弱带还高；±50 的排除区挡不住它，拼图里每个位置都标了一条 75-76 的标签。
- 单点尖峰：一条谱里最多 1 个 6σ 以上的单点跳变（1100\15-2 在 1418 cm-1，+7 counts）；但 H 用原始采样点、宽度不判，3-11 counts 的单点毛刺能直接过阈值。重复谱交叉验证里 64% 的假峰半高宽 ≤ 3 个采样点。

统计底部：把“没有任何真实带”的 1200 cm-1 以上区间当作噪声本底，124 条谱上 H/σ 的中位数 3.6、90 分位 4.8、最大 7.1。原因是 H 的基线取 ±60 cm-1 内两侧极小值中较高者，在纯噪声谱上这个基线天然比局部电平低 1-1.5σ，所以 2.5σ 的名义阈值实际只有 1σ 左右的显著性。
