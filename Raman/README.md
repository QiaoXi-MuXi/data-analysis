# Raman 出图工具

## 快速使用

| 项目 | 说明 |
|---|---|
| 输入 | `data/` 内两列光谱 TXT。自动扫描按文件名自然顺序排列（`1-1`、`1-2`、`1-10`、`2-1`、`10-1`），避免 `10-1` 跑到 `2-1` 前。基准对比模式使用 `compare.xlsx` 中指定的基准谱与样品谱。 |
| 配置 | `stack.xlsx` 控制堆叠图；`compare.xlsx` 控制基准对比分析；`montage.xlsx` 控制拼图；`batch_display.xlsx` 控制分层批次展示；无配置表时保留交互单谱模式。`fill_stack.bat` 按数据重建 `stack.xlsx`（`--target montage --src <目录>` 则重建拼图表），请先确认输入目录。 |
| 运行 | 双击本目录唯一的 `run.bat`，参数原样传递；基准对比使用 `run.bat --compare compare.xlsx`，拼图使用 `run.bat --montage`，分层批次展示使用 `run.bat --batch-display --src <输入根目录>`。 |
| 输出 | 默认按模式分目录：单谱 `out/single/`、堆叠 `out/stack/`、拼图 `out/montage/`、基准对比 `out/compare/`、批次展示 `out/batch_display/`；显式 `--out` 可覆盖。 |
| 环境检查 | 运行根目录 `check.bat`；使用共享 `../python/python.exe`，不回退系统 Python。 |

命令行无人值守运行可在当前 PowerShell 设置 `$env:DATA_ANALYSIS_NO_PAUSE='1'`，使失败时直接返回退出码；该设置不取消 Raman 无参数单谱模式的输入提示。检查后可用 `Remove-Item Env:DATA_ANALYSIS_NO_PAUSE` 移除。原始输入及现有输出位置保持原有约定。

双击 `run.bat` 即可出图。原有两种模式靠 `stack.xlsx` 在不在切换，第三种基准对比必须通过 `--compare` 显式启动，不会因为存在 `compare.xlsx` 就自动切换：

| 模式 | 触发条件 | 干什么 |
|---|---|---|
| **堆叠对比** | 有 `stack.xlsx` | 按表格把多条谱错开颜色叠在一张图，**同时每行各出一张单谱图**，全自动，不问任何参数 |
| **单谱** | 没有 `stack.xlsx` | 每个 txt 一张图并标峰位，运行时问区间和峰高 |
| **拼图** | `run.bat --montage` | 上方放实物照片，下方放该样品各位置的谱，一个样品合成一张图；默认按文件名自动配对，也可用 `montage.xlsx` 指定 |
| **基准对比分析** | `run.bat --compare compare.xlsx` | 一个基准谱对多个样品做全峰检测、峰一一匹配、缺失/新增峰识别、峰位偏差和全谱 Pearson，定量输出并追溯 |

前两种模式双击 `run.bat`，成功都直接关窗口，只有出错才停下来等你按键看提示；`--compare` 属于命令行入口，同样遵守失败暂停和退出码约定。

默认输出互相隔离，避免一次运行清掉另一种模式的结果：

```
out/
  single/       单谱图、peaks.csv
  stack/        堆叠图、逐样品图
  montage/      拼图、montage_peaks.csv
  compare/      对比 CSV、逐样品对比图、偏差图、compare_run.json
```

只有显式传入 `--out` 时才写到指定目录；目录内旧产物仍按原规则清理。四种模式不会自动连续运行。

单谱模式下运行时会依次问三项：区间左边界、区间右边界、峰高阈值，**直接回车就用默认值**，三项都回车等于不用管参数。区间默认值不是写死的，而是运行时从 `data` 里所有 txt 的波数读出最小值和最大值（当前这批数据是 -106.52 – 3736.17 cm⁻¹），所以换一批数据不用改任何东西，默认就是全谱。峰高阈值回车 = 自适应：按每条谱自己的噪声和最强峰算 `max(5.5σ, 1.1%×最强峰 H)`，弱信号谱不会被固定阈值标出一堆噪声鼓包。

## 堆叠对比图（stack.xlsx）

拉曼不同样品的对比常要看峰位偏移，这时用 Excel 表格配置，不用每次在窗口里敲。双击打开 `stack.xlsx`，在「配置」表里改内容，存盘后双击 `run.bat` 就出图。`stack.xlsx` 正被 Excel 打开时仍能出图，但程序会提示本次读取磁盘上已保存的版本，未保存的修改不会生效；建议存盘关闭后运行。下表为「配置」表的列说明：

| 文件 | 图例名称 | 归一化(0/1) | 标注峰位(0/1) | 峰高阈值 | 纵向偏移 | 区间下限 | 区间上限 |
|---|---|---|---|---|---|---|---|
| 0-1.txt | 样品 0-1 | 1 | 1 | | | | |
| 0-2.txt | 样品 0-2 | 1 | 1 | | | | |

| 列 | 含义 |
|---|---|
| `文件` | `data` 里的 txt 文件名，`.txt` 可省略，必填；也支持一级子目录，写成 `1100\1-1.txt` |
| `图例名称` | 图上显示的名字，用 `\|` 换行（如 `样品 A\|三次平均`），留空则用文件名 |
| `归一化(0/1)` | `1` = 每条谱缩放到自己的 0~1 范围；`0` = 保留原始强度 |
| `标注峰位(0/1)` | `1` = 在这条谱上标峰位；`0` = 不标。留空也标 |
| `峰高阈值` | 标峰阈值，单位 counts（按原始强度判断）；留空用这条谱的自适应值。双击 `fill_stack.bat` 后本列会被自动重算为每条谱的自适应值 `max(5.5σ, 1.1%×最强峰 H)`——弱信号谱阈值随噪声抬高、不会把噪声鼓包标成峰，高动态谱阈值再随主峰抬高、压掉中等杂散峰；想保留自己手填的值，命令行跑 `fill_stack.bat --keep-height` |
| `纵向偏移` | 纵向偏移量，留空自动排布（一般不用填） |
| `区间下限` / `区间上限` | 横向显示区间；可以只填一端，空的那端自动取数据边界（下限取最小值、上限取最大值）；两端都留空 = 数据全范围 |

规则：

- 只读第一个工作表（「配置」），第二个工作表「说明」只是给你看的备注，不影响出图
- 列的顺序无所谓，脚本按表头名字找列；表头不区分大小写
- 表头中英文都认：`文件`/`file`、`图例名称`/`label`、`归一化`/`normalize`、`标注峰位`/`peaks`、`峰高阈值`/`height`、`纵向偏移`/`offset`、`区间下限`/`xmin`、`区间上限`/`xmax`
- 括号里的 `(0/1)` 只是提示，写不写都认
- 行的顺序 = 图上从下往上的顺序，第一条在最下面
- 颜色按顺序自动分配（红、蓝、绿、紫……），最多 8 种后循环；图例固定在右上角
- 峰位标注可以和单谱模式不一样：每条谱单独用 `peaks` 开关，用 `height` 单独设阈值
- 相邻峰位标签会上下错层显示，不会被删掉
- `normalize` 必须全表一致，不能混用——归一化和原始强度画在一张图里，弱的谱会被压成一条直线，脚本会直接报错提示
- 归一化时纵轴不标数字（标了也没意义），轴标题变成 `norm.`
- 空行会被跳过；某行 `file` 留空也跳过，可以拿来当分隔行
- 文件名写错会报 `ERROR: no such file: ...`，退出码 1

产物：`out\stack.png`（合并图）+ 表格里**每一行各自一张单谱图** `out\<文件名>.png`。行里带子目录时单谱图也带前缀（`1100\1-1.txt` → `out\1100-1-1.png`），否则两个数据集里同名的 `1-1` 会互相覆盖。

两张图用的不是同一套排版，各有各的标准：

| | 合并图 `stack.png` | 单谱图 `<文件名>.png` |
|---|---|---|
| 颜色 | 按行循环，每条不同 | 统一红色 |
| 纵向 | 上下错开，每条一条基线 | 单条谱占满画布 |
| 纵轴 | 原始强度才标数字 | 同左 |
| 峰位数量 | 谱多时只标最高的 3~5 个，避免糊成一片 | 最多 10 个，够用就全标 |
| 标注字号 | 按谱条数自适应缩小 | 固定正常字号 |
| 画布 | 谱多时自动变高、图例移到框外 | 固定 2048×1024 |

两边的 `peaks` / `height` 读的是同一行，所以同一条谱在两张图上的峰位是同一个值，只是标注密度不同。单谱图不写 `peaks.csv`。

**想回到单谱模式**：把 `stack.xlsx` 改名成 `stack.xlsx.bak` 即可，`run.bat` 会自动走单谱流程。

**想让表格跟 data 里的文件对齐**：双击 `fill_stack.bat`。它按 data 里现有的 txt 重建表格：行顺序跟 data 一致，data 里已经删掉的文件对应行也会一起去掉；同名文件你改过的（label、normalize、peaks 等）原样保留。stack.xlsx 不存在时直接按 data 里的全部文件新建。

**多套数据放在同一张表**：`data\` 下按一级子目录分数据集（`data\Raman\1100\1-1.txt`、`data\Raman\1210\1-1.txt`、根目录 `0-1.txt`），文件名重名也不会撞行。填表时把真正的数据根传给 `--src`：

```powershell
.\fill_stack.bat --target stack --src "data\Raman" --exclude "0-4.txt" --exclude "0-5.txt"
```

子目录里的行默认把目录写进图例（`1100 1-1`），否则图例里会出现一堆同名的 `1-1`；`--exclude` 按相对路径或纯文件名排除（可写多次）。出图时 `--src` 要和填表时保持一致：`run.bat --stack stack.xlsx --src "data\Raman"`。

**峰高阈值（height 列）会自动填**：`fill_stack.bat` 默认按每条谱重算阈值 `max(5.5σ, 1.1%×最强峰 H)`——σ 是该谱的噪声基底（差分 MAD 稳健估计），强信号谱阈值随主峰自动抬高、压掉中等杂散峰，弱信号谱则按噪声抬高。124 条实测谱（41 个位置 × 3 次）的验收口径：旧口径 2.5σ 共标 604 个标签，其中 221 个在 1200 cm⁻¹ 以上没有任何真实带的区间、282 个在同一位置的重复谱里只出现一两次；新口径 298 个，1200 cm⁻¹ 以上 0 个，重复谱对不上的 28 个，单谱最多 3 个标签；144/566/762 三个真带分别保留 77、124、124 条谱（丢的几条是信号本身只有 4-5σ 的最弱谱）。你手填的 height 值会被重算覆盖；想保留手填值，用命令行 `fill_stack.bat --keep-height`（双击 bat 不会带这个参数）。

## 拼图（实物图 + 位置谱）

一张图回答“这个位置上打出来的谱是什么样”：上方是显微实物照片，下方是该样品几个测量位置的光谱。一个样品一张图，不把不同样品混在一起。

### 命名约定（不写配置表时自动配对）

```
1100\1-1-1.png          实物照片
1100\1-1.txt  1-2.txt  1-3.txt    位置 1 / 2 / 3 的谱
```

- 实物图文件名以 `-1-1` 结尾，组名就是去掉 `-1-1` 的部分：`1-1-1.png` → 组 `1`，`20-1-1.png` → 组 `20`
- 光谱是 `组名-序号.txt`，按序号从小到大排，序号顺序就是图上从下往上的顺序
- 组名前缀整段匹配，`1-` 不会把 `10-1.txt` 抢过来；`2-` 也不会吃掉 `20-2.txt`
- 已经出好的谱图（`1-1.png`）不以 `-1-1` 结尾，**不会**被当成实物图
- 某组只有 2 个位置（例如缺了 `20-1.txt`）照样能拼；某组完全没有实物图就跳过并提示

### 运行

```powershell
.\run.bat --montage --src "..\20261123\Raman\1100"
& ..\python\python.exe -B .\plot_raman.py --montage --src '..\20261123\Raman\1100'
.\run.bat --montage .\montage.xlsx --src "..\20261123\Raman\1100"
```

`--src` 指向同时放着实物图和 txt 的目录（不是固定 `data\`）；不写 `--out` 时写入 `out\montage\`。`--xmin/--xmax` 可选，要么都写要么都不写；`--shift`、`--zero-guard`、`--height` 与单谱模式同义。

### `montage.xlsx` 配置表

自动扫描只认 `<组名>-1-1` 这一种实物图名。换成 `sample.png` 这类名字、或者想改图例/颜色/阈值时用它：**一行一条光谱，组名相同的行合成一张拼图**。

| 组名 | 实物图 | 文件 | 图例名称 | 归一化(0/1) | 标注峰位(0/1) | 峰高阈值 | 颜色 | 纵向偏移 | 区间下限 | 区间上限 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 1-1-1.png | 1-1.txt | 位置 1 | 1 | 1 | | #e01b24 | | | |
| 1 | | 1-2.txt | 位置 2 | 1 | 1 | | #0f9d58 | | | |

| 列 | 含义 |
|---|---|
| `组名` | 这一组的名字，也是输出文件名；留空按文件主名推（`1-2.txt` → `1`） |
| `实物图` | 照片路径，相对 `--src`；也能写绝对路径。支持 png/jpg/tif/bmp，每组写一次即可 |
| `文件` | `--src` 里的光谱 txt，`.txt` 可省略，必填 |
| `图例名称` | 图例里的位置名，`\|` 可换行，留空用文件名 |
| `归一化(0/1)` | `1` = 该条谱缩放到 0~1；`0` = 原始 counts。**同一组必须一致**，混用会报错 |
| `标注峰位(0/1)` | `1` 或留空 = 标峰；`0` = 这条谱不标（比较图上的峰太密时很有用） |
| `峰高阈值` | 标峰阈值，原始 counts；留空按这条谱的自适应值 `max(5.5σ, 1.1%×最强峰 H)`，要固定阈值就在行里填数或用命令行 `--height` |
| `颜色` | 谱线颜色，`#RRGGBB` 或 `red`/`blue` 这类名字；留空按红、绿、蓝顺序 |
| `纵向偏移` | 纵向错开量，留空自动排布，一般不用填 |
| `区间下限` / `区间上限` | 横向区间，可只填一端，空的一端取数据边界 |

表头中英文都认（`group`/`photo`/`file`/`label`/`normalize`/`peaks`/`height`/`color`/`offset`/`xmin`/`xmax`），括号里的 `(0/1)` 只是提示。空行和首格以 `#` 开头的行跳过。组名重复但参数冲突（例如同一组填了两个不同的区间上限）、颜色写错、光谱或实物图不存在，都会明确报错，不会静默用默认值。

模板生成：

```powershell
& ..\python\python.exe -B .\_make_montage_xlsx.py                     # 空模板（表头 + 说明）
& ..\python\python.exe -B .\_make_montage_xlsx.py --from-src ..\1100  # 按该目录自动配对的结果预填
```

已有 `montage.xlsx` 时默认拒绝覆盖，确需重建加 `--force`。

### 按目录整表重填（`fill_stack.bat --target montage`）

表是给“命名不规矩、要改图例/颜色”的情况用的；只要实物图叫 `<组名>-1-1.png`，就别手抄，让脚本按目录重建：

```powershell
.\fill_stack.bat --target montage --src "..\20261123\Raman\1100"
```

填充策略跟 `stack.xlsx` 不同：它按实物图分组，每组每个位置写一行；同一组同一文件你改过的图例名称、归一化、标峰、峰高阈值、颜色、偏移、区间都**原样保留**，源目录里已经删掉的谱对应行会去掉，新出现的谱补在组尾并沿用该组的归一化设置。组名空着的旧行按文件名推组名（`1-2.txt` → `1`），也能对上。`--path` 可指定别的表文件，不写就覆盖本目录的 `montage.xlsx`。

### 版式

- 上方实物图按原始长宽比缩放，**左右边缘与下方谱图区严格等宽**（不再各留一条白边）；高度由照片比例决定，只有极端竖长的照片才缩窄，外框用和谱图一样的细黑线
- 下方一条坐标轴：各位置的谱按基线纵向错开，位置 1/2/3 默认红/绿/蓝——正好对上显微照片上常见的三色十字标记，看谱就知道打的是哪个点（颜色可在表里改）
- 图例横排在坐标轴**上方框外**：拉曼谱右端常有一段荧光背景和小峰，图例搁框里必和峰位标签打架
- 峰位仍是同一套高斯 + 线性基线拟合；每条谱最多标最高的 6 个峰，标签挨太近时错层 4 档，不会被删掉
- 图中文字字号、刻度长度、2048 px 宽度全部沿用单谱/堆叠图，拼图和三张图放一起不违和

### 产物

| 文件 | 内容 |
|---|---|
| `montage\<组名>.png` | 2048 宽，高度随照片比例（这批数据约 2393 px） |
| `montage\montage_peaks.csv` | `group,file,peak_cm-1,I_max,H_counts`，逐组逐谱的峰位和峰高，`utf-8-sig` |

### 读图注意

- **纵刻度的数字是“错开后的位置”**，只适合看单条谱自身的相对强弱；跨位置比较峰高请看 `montage_peaks.csv` 里的 `H`（`H = I_max - I_baseline`，口径同单谱）
- 低波数端 0 cm⁻¹ 附近是激光线（瑞利散射）漏光，默认 ±50 cm⁻¹ 内不认峰；144 cm⁻¹ 的最低真带在区外。再往外的低频特征（如 76 cm⁻¹）正常标注，需要更宽的排除区时用 `--zero-guard 100`，想看原始漏光峰时用 0
- 实物图尺寸正好是 2048×1024 时会提示“确认是不是实物图”——那是本工具出图尺寸，多半是把谱图误存成了照片
- 退出码：全部成功 0；部分组失败（图没写出来或区间内点太少）2；一个都没成功 1

## 基准对比分析（compare.xlsx）

堆叠图回答“看起来像不像”，基准对比回答“哪些峰对得上、偏了多少、少了或多了哪些峰”。它用一个基准谱对多个样品谱做全峰检测和一一匹配，输出可复核的表格、图像和运行清单；不把多个指标合成“相似度百分比”，也不做物相鉴定。

### 启动与配置

```powershell
# 在 Raman 目录
.\run.bat --compare .\compare.xlsx
& ..\python\python.exe -B .\plot_raman.py --compare .\compare.xlsx --src .\data --out '独立结果目录'
```

- `--compare` 与 `--stack` 互斥；只写一个 `--compare` 时不会走单谱或堆叠流程。
- 无参数双击 `run.bat` 仍按原来的 `stack.xlsx` / 单谱规则切换，不会因为存在 `compare.xlsx` 自动进入对比模式。
- `--xmin/--xmax` 必须同时提供；只给一个会返回参数错误（退出码 2）。
- `--src` 是样品目录；不写 `--out` 时，对比结果写入 `out/compare`。

模板可用下面的命令生成；目标文件已存在时默认拒绝覆盖，只有显式 `--force` 才覆盖：

```powershell
& ..\python\python.exe -B .\_make_compare_xlsx.py .\compare.xlsx
```

模板自带占位基准 `reference/基准.txt`，没有样品行；直接运行会因“基准不存在”或“没有启用样品”报错，这是提示你填写，不是程序故障。

**`样品` 表**（第一张表）：

| 列 | 必填 | 空白默认 | 说明 |
|---|---:|---|---|
| `文件` | 是 | 无 | 样品 TXT；相对 `--src`，`.txt` 可省略 |
| `图例名称` | 否 | 文件主名 | 图表和表格名称；图例里 `\|` 可换行，CSV 中仍是一行 |
| `启用(0/1)` | 否 | 1 | 0 表示保留行但不参与本次分析 |
| `峰高阈值` | 否 | 自动 | 原始 counts；留空按该样品共同窗口自适应 |
| `标注峰位(0/1)` | 否 | 1 | 只影响图上标签密度，不裁剪分析峰 |

空行和首单元格以 `#` 开头的行跳过；中英文别名都认。至少要有条启用样品。

**`参数` 表**（固定 `参数`、`值`、`说明` 三列）：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `基准文件` | 必填 | 一个两列 TXT；路径相对于 `compare.xlsx` 所在目录，推荐 `reference/xxx.txt` |
| `基准名称` | 文件主名 | 图例和运行清单中的名称 |
| `基准峰高阈值` | 自动 | 原始 counts；留空按共同窗口自适应 |
| `区间下限` / `区间上限` | 共同交集 | 必须同时填写或同时留空；显式超出任一样品范围会报错，不外推 |
| `匹配容差` | 10 | 正数，cm⁻¹；只有 `abs(峰位差) <= 容差` 才可匹配 |
| `归一化(0/1)` | 1 | 比较图和残差图逐谱缩放到共同窗口 0–1；不改变 H 检测口径 |
| `峰位校正` | 0 | 同时加到基准和样品的波数，等价于单谱 `XSHIFT` |
| `激光线排除半宽` | 50 | 非负数，0 表示关闭；以校正后激光线位置为中心，只覆盖激光线漏光，144 cm⁻¹ 真带不受影响 |

重复参数、未知参数、非法开关、非有限数值、公式单元格都会明确报错，不静默使用默认值。未填的默认值会写进 `compare_run.json`。

### 分析口径

- 基准和样品都读取前两列，要求严格升序或严格降序、无重复波数、无 NaN/Inf；不静默排序或去重。
- 峰检测复用单谱的平滑、局部极大、`H = I_max - I_baseline`、高斯 + 线性基线拟合和激光线排除。分析使用**全部检测峰**，不受单谱图最多 10 个标签的限制。
- 没有指定区间时，取“基准 + 所有启用样品”波数范围的交集；共同窗口少于 8 点时终止。
- 峰匹配用保持波数顺序的一一匹配：先最大化匹配对数，再最小化绝对偏差和，最后确定性回溯。不会用简单最近邻贪心，也不会一个峰匹配多个峰。
- 全谱 Pearson 使用共同窗口内线性插值后的原始强度；它衡量整段曲线相似性，包含未匹配峰和基线趋势，不是物相鉴定概率。
- 峰位偏差 `delta = 样品峰位 - 基准峰位`。`match_rate = 匹配峰数 / 基准峰数`。没有匹配峰时，偏差统计留空，不写 0。
- `H_ratio` 是原始 H 比；`H_norm` 按共同窗口强度跨度归一化，`H_norm_ratio` 是其比值。跨谱强度比会受采集条件和归一化影响，不能直接当浓度。

### 图形界面

Raman 的处理模式下拉新增“基准对比分析”，需要设置基准光谱 TXT、基准峰高阈值、匹配容差、对比归一化、激光线排除半宽和区间；全局峰高阈值在该模式下禁用，逐样品阈值在样本表里填。运行会生成独立 `config.xlsx` 快照，基准和样品都进入 SHA256 冻结；运行后改动基准会标记为 `review`。Excel 导入/导出使用同一 `compare.xlsx` 三表格式。

不需要对比时保持原来的“使用界面中的项目配置”或“扫描目录 / 单独处理”即可，旧项目和旧 `stack.xlsx` 的默认行为不变。

## 默认预设（单谱模式）

| 参数 | 默认值 | 含义 |
|---|---|---|
| XMIN | data 里波数最小值 | 区间左边界，cm⁻¹ |
| XMAX | data 里波数最大值 | 区间右边界，cm⁻¹ |
| HEIGHT | 自适应（回车 = 空） | 峰高阈值，counts；留空按每条谱算 `max(5.5σ, 1.1%×最强峰 H)` |
| XSHIFT | 0 | 峰位校正量，cm⁻¹ |

XMIN / XMAX 在运行时由 `run.bat` 扫描 `data\*.txt` 第一列自动算出（取所有文件的最小/最大值，四舍五入到两位小数），所以默认画的就是全谱。想改峰高阈值或校正量，改 `run.bat` 开头那两行（`HEIGHT` 留空即自适应，填数字就是全批统一的固定阈值）；区间这类一次性调整直接在提示处输入即可，只对当次生效。

如果数据文件读不出来，区间会退回 500 – 1000 并在窗口里提示。

## 峰位校正 XSHIFT

所有波数整体平移这个量：

- **正数**：峰整体向右（往大波数）移
- **负数**：峰整体向左（往小波数）移
- **0**：不校正

例如仪器读数系统性偏大 12 cm⁻¹，就设 `XSHIFT=-12`，图上峰位会整体减小 12。

轴范围始终是 XMIN–XMAX。也就是说校正只改变「这个峰被标成多少」，不会改变「看的是哪一段数据」——脚本会自动把取数窗口反向补偿。

`out\peaks.csv` 里带一列 `shift_cm-1`，记录本次用的校正量，方便回溯。

## 峰高 H 的定义

```
H = I_max - I_baseline
```

- `I_max`：峰顶处的实测强度
- `I_baseline`：峰两侧 ±60 cm⁻¹ 范围内两个局部极小值中**较高**的那个

这是从数据本身估出来的背景，不是仪器测的基线。所以 H 只适合在同一批数据内部比较峰的高低，不要当成绝对强度。

只有 `H >= HEIGHT` 的峰才会标注波数；此外还要求半高宽至少跨 2 个采样点（单点宇宙线/坏点平滑后到不了半高，计数为 0）。峰位由高斯 + 线性基线拟合给出，拟合窗口 ±30 cm⁻¹。

自适应阈值是 `max(5.5σ, 1.1%×最强峰 H)`。k 取 5.5 而不是 2.5，是因为 H 的基线取 ±60 cm⁻¹ 内两侧极小值中较高的那个，在纯噪声谱上这个基线天然比局部电平低 1-1.5σ，表观 H/σ 并不是真显著性。124 条实测谱上统计"没有真实带"的 1200 cm⁻¹ 以上区间：H/σ 中位数 3.6、90 分位 4.8、最大 7.1，所以 5.5 能压住噪声而 2.5 压不住。

## 激光线假峰排除

0 cm⁻¹ 附近有激光线（瑞利散射）的漏光，紧跟着一段从本底陡升的台阶，台阶顶会被局部极大判据当成一个又尖又高的"峰"（H 可达 50-90 counts，比 762 cm⁻¹ 的弱带还高）。脚本默认把以激光线为中心 ±50 cm⁻¹ 内的局部极大直接排除，不做拟合。

- 半宽取 50：144 cm⁻¹ 处最低的真实带正好在排除区之外，不会被误伤；再往外的低波数特征（例如 76 cm⁻¹ 那条）照常参与检测和标注
- 排除区以**校正后的激光线位置**为中心：单谱模式跟着 `XSHIFT` 走（例如 `XSHIFT=+10` 时排除区变成 -50 ~ +60），堆叠模式以 0 为中心
- 用命令行参数 `--zero-guard` 改半宽；设 `--zero-guard 0` 可关闭排除（想看原始漏光峰时用）
- 单谱、堆叠、拼图三种模式都默认生效；`run.bat` 直接运行时用默认值，命令行模式可传 `--zero-guard`

### 76 cm⁻¹ 处的低频特征

0 J/cm² 的五条原样谱在 55-95 cm⁻¹ 几乎是平的（50-90 cm⁻¹ 内起伏 4-11 counts，就是噪声）；1100 系列前 11 个位置、1210 系列前 12 个位置同样只有 3-20 counts。从 1100 的 P12 和 1210 的 P13 起，这一段突然抬到 30-795 counts 并随能量继续增大（1100 P20 到 466 counts、1210 P16 到 795 counts），正好落在烧蚀开始的能量附近。所以它**不是**滤光片截止边（那是固定的仪器边，任何谱都会有），而是加工诱发的低波数结构，正常参与峰位标注，图上不做任何额外记号。读数时按能出现的能量段去看它，别拿它跟 0 J 原样谱的同一位置比。

## 输出

- 单谱模式：`out\<文件名>.png`，每份 txt 一张，2048×1024
- 单谱模式：`out\single\peaks.csv`，峰位表，列为 文件、峰位、H、I_max、I_baseline、校正量
- 堆叠模式：`out\stack\stack.png`，一张对比图；逐样品单图也在同目录
- 拼图模式：`out\montage\<组名>.png`，一个样品一张（实物图 + 该样品全部位置谱）＋ `montage_peaks.csv`
- 基准对比模式：`out\compare\` 下的三张 `compare_*.csv`、逐样品 `compare_<样品主名>.png`、全批 `compare_shift.png` 和 `compare_run.json`；文件名与字段见上一节

每次运行都会**先清空 `out` 里的旧文件**（png / csv 等普通文件，不动子目录），再生成新图。这样 data 里已经删掉的谱对应的旧图不会残留在 out 里让人误认。清空只删普通文件；个别文件被占用（比如图片还开着）删不掉时会警告并跳过，不影响本次出图。

图片先写成临时文件再替换过去，所以不会出现写了一半的残图。如果某个文件被占用（比如图片还开着），会自动重试三次；仍然失败的话只跳过这一个文件，其余照常出图，并在窗口里列出失败的文件名。

> 注意：因为每次会先清空，`out` 目录请专门用来放本工具的产物，不要把其它想保留的文件放在里面。

## 速度

两种既有模式都是按文件并行出图：每个 txt 的读取、找峰、画单图在一个子进程里一次做完，合并图复用同一批结果，不重算。基准对比为保证匹配和汇总顺序确定，按样品顺序处理。

- 26 条谱：堆叠模式约 1.8 s，单谱模式约 1.6 s（16 核机器实测，含进程启动）
- 20 组拼图（58 条谱 + 20 张 2.6 MB 显微照片）：约 15 s，串行——瓶颈在读照片和写 PNG，不在找峰，不值得开进程池
- 少于 5 条谱或只有单核时自动走串行，避免进程启动开销超过收益
- 进程池起不来（受限环境）会静默退回串行，不会导致出图失败

## 分层批次展示（batch-display）

当一批数据有「多个基准 + 两组 × 多点点位 × 同点多扫描」时，堆叠图和单基准对比都会太密。第四种模式把展示拆成四层，从首页逐层定位，不画几十条曲线的合图：

| 层 | 看什么 | 产物 |
|---|---|---|
| 1 总览 | 5 条基准总览 + 每组一张 4×5 点位缩略图（不标峰） | 00_reference_overview.png、01_1100_contact.png、02_1210_contact.png |
| 2 点位 | 单点三次原始扫描 + 实物图；同点重复叠加与显示差值 | points/组/P点号.png、repeats/组/P点号_repeat.png |
| 3 跨组 | 同一点号 1100 与 1210 的代表谱对比与差值 | paired/P点号_1100_vs_1210.png、tables/pair_summary.csv |
| 4 指标 | 每个基准分开的 Pearson、匹配率、逐基准峰位偏移 | metrics/基准/{pearson,match_rate,peak_shift}.png、compare_points/基准/组/P点号.png |

入口：

```powershell
# 自动发现（必须显式 --src 指向输入根目录，不猜目录）
.\run.bat --batch-display --src '..\20261123\Raman'
# 或用配置表
.\run.bat --batch-display .\batch_display.xlsx --src '..\20261123\Raman'
# 生成配置表模板（--src 时自动预填光谱/基准清单）
& ..\python\python.exe -B .\_make_batch_display_xlsx.py .\batch_display.xlsx --src '..\20261123\Raman'
```

自动发现规则：根目录 0-1.txt…0-5.txt 识别为基准；一级子目录为组；组内 点-扫描.txt（如 1-1.txt、20-3.txt）是光谱，点-1-1.png 是实物图。点号是不同位置、扫描号是同点重复，两者不混。旧 PNG、CSV、其它文件记为警告，不纳入分析；缺少某个扫描记为 partial（实际 n 少于期望），不补值、不中断。

batch_display.xlsx 四表：「光谱」（文件/组名/点号/扫描号/图例/启用/峰高阈值/实物图）、「基准」（基准ID/文件/图例/启用/峰高阈值）、「参数」（18 项）、「说明」。参数里「代表谱」可设 mean（默认，公共网格显示均值）/first（最小扫描号）/none（不画代表线），「归一化」只影响显示，定量仍复用现有 compare 核心。

结果在 out/batch_display/，从 index.html 进入，离线可开。数值表在 tables/：scan_metrics.csv（基准×组×点×扫描）、point_summary.csv（基准×组×点）、peak_matches.csv（复用 compare 峰级字段）、pair_summary.csv，加根目录 batch_manifest.csv 与 batch_run.json。全部 utf-8-sig；失败与无值留空，不写 0。
