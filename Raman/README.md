# Raman 出图工具

双击 `run.bat` 即可出图，有两种模式，靠 `stack.xlsx` 在不在切换：

| 模式 | 触发条件 | 干什么 |
|---|---|---|
| **堆叠对比** | 有 `stack.xlsx` | 按表格把多条谱错开颜色叠在一张图，**同时每行各出一张单谱图**，全自动，不问任何参数 |
| **单谱** | 没有 `stack.xlsx` | 每个 txt 一张图并标峰位，运行时问区间和峰高 |

两个 bat 跑成功都直接关窗口，只有出错才停下来等你按键看提示。

单谱模式下运行时会依次问三项：区间左边界、区间右边界、峰高阈值，**直接回车就用默认值**，三项都回车等于不用管参数。区间默认值不是写死的，而是运行时从 `data` 里所有 txt 的波数读出最小值和最大值（当前这批数据是 95.59 – 3863.12 cm⁻¹），所以换一批数据不用改任何东西，默认就是全谱。

## 目录

```
data analysis\
  python\          便携 Python 3.12 + numpy / matplotlib（Ra 和 Raman 共用）
  Raman\
    run.bat        双击运行
    plot_raman.py  出图脚本
    stack.xlsx     堆叠对比图的配置表（Excel，不需要就改名）
    fill_stack.bat 双击把 data 里所有 txt 补进 stack.xlsx
    _fill_stack.py 上者调用的脚本
    _make_stack_xlsx.py  重新生成 stack.xlsx 模板
    _check_columns.py    核对 代码/表格/README 三处列名是否一致
    data\          放 txt 数据（两列：波数、强度）
    out\           图片输出到这里
    README.md
```

`run.bat` 用 `%~dp0..\python\python.exe` 定位解释器，路径全相对，
整个 `data analysis` 文件夹拷到别的电脑照样能跑。

## 堆叠对比图（stack.xlsx）

拉曼不同样品的对比常要看峰位偏移，这时用 Excel 表格配置，不用每次在窗口里敲。双击打开 `stack.xlsx`，在「配置」表里改内容，存盘后双击 `run.bat` 就出图：

| 文件 | 图例名称 | 归一化(0/1) | 标注峰位(0/1) | 峰高阈值 | 纵向偏移 | 区间下限 | 区间上限 |
|---|---|---|---|---|---|---|---|
| 0-1.txt | 样品 0-1 | 1 | 1 | | | | |
| 0-2.txt | 样品 0-2 | 1 | 1 | | | | |

| 列 | 含义 |
|---|---|
| `文件` | `data` 里的 txt 文件名，`.txt` 可省略，必填 |
| `图例名称` | 图上显示的名字，用 `\|` 换行（如 `样品 A\|三次平均`），留空则用文件名 |
| `归一化(0/1)` | `1` = 每条谱缩放到自己的 0~1 范围；`0` = 保留原始强度 |
| `标注峰位(0/1)` | `1` = 在这条谱上标峰位；`0` = 不标。留空也标 |
| `峰高阈值` | 标峰阈值，单位 counts（按原始强度判断）；留空用默认 5 |
| `纵向偏移` | 纵向偏移量，留空自动排布（一般不用填） |
| `区间下限` / `区间上限` | 横向显示区间，留空 = 数据全范围；两列要么都填要么都空 |

规则：

- 只读第一个工作表（「配置」），第二个工作表「说明」只是给你看的备注，不影响出图
- 列的顺序无所谓，脚本按表头名字找列；表头不区分大小写
- 表头中英文都认：`文件`/`file`、`图例名称`/`label`、`归一化`/`normalize`、`标注峰位`/`peaks`、`峰高阈值`/`height`、`纵向偏移`/`offset`、`区间下限`/`xmin`、`区间上限`/`xmax`
- 括号里的 `(0/1)` 只是提示，写不写都认
- 行的顺序 = 图上从下往上的顺序，第一条在最下面
- 颜色按顺序自动分配（红、蓝、绿、紫……），最多 8 种后循环；图例固定在右上角
- 峰位标注可以和单谱模式不一样：每条谱单独用 `peaks` 开关，用 `height` 单独设阈值
- 相邻峰位标签会上下错层显示，不会被删掉
- `normalize` 必须全表一致，不能混用——归一化和原始强度画在一张图里，弱的谱会被压成一条直线，脚本会直接报错提示
- 归一化时纵轴不标数字（标了也没意义），轴标题变成 `norm.`
- 空行会被跳过；某行 `file` 留空也跳过，可以拿来当分隔行
- 文件名写错会报 `ERROR: no such file: ...`，退出码 1

产物：`out\stack.png`（合并图）+ 表格里**每一行各自一张单谱图** `out\<文件名>.png`。

两张图用的不是同一套排版，各有各的标准：

| | 合并图 `stack.png` | 单谱图 `<文件名>.png` |
|---|---|---|
| 颜色 | 按行循环，每条不同 | 统一红色 |
| 纵向 | 上下错开，每条一条基线 | 单条谱占满画布 |
| 纵轴 | 原始强度才标数字 | 同左 |
| 峰位数量 | 谱多时只标最高的 3~5 个，避免糊成一片 | 最多 10 个，够用就全标 |
| 标注字号 | 按谱条数自适应缩小 | 固定正常字号 |
| 画布 | 谱多时自动变高、图例移到框外 | 固定 2048×1024 |

两边的 `peaks` / `height` 读的是同一行，所以同一条谱在两张图上的峰位是同一个值，只是标注密度不同。单谱图不写 `peaks.csv`。

**想回到单谱模式**：把 `stack.xlsx` 改名成 `stack.xlsx.bak` 即可，`run.bat` 会自动走单谱流程。

**想把 data 里所有文件一次性列进表格**：双击 `fill_stack.bat`。它只**追加** data 里还没有的文件，你已经改过的行（label、normalize、peaks、height 等）原样保留。stack.xlsx 不存在时直接按 data 里的全部文件新建。

## 默认预设（单谱模式）

| 参数 | 默认值 | 含义 |
|---|---|---|
| XMIN | data 里波数最小值 | 区间左边界，cm⁻¹ |
| XMAX | data 里波数最大值 | 区间右边界，cm⁻¹ |
| HEIGHT | 5 | 峰高阈值，counts |
| XSHIFT | 0 | 峰位校正量，cm⁻¹ |

XMIN / XMAX 在运行时由 `run.bat` 扫描 `data\*.txt` 第一列自动算出（取所有文件的最小/最大值，四舍五入到两位小数），所以默认画的就是全谱。想改峰高阈值或校正量，改 `run.bat` 开头那两行；区间这类一次性调整直接在提示处输入即可，只对当次生效。

如果数据文件读不出来，区间会退回 500 – 1000 并在窗口里提示。

## 峰位校正 XSHIFT

所有波数整体平移这个量：

- **正数**：峰整体向右（往大波数）移
- **负数**：峰整体向左（往小波数）移
- **0**：不校正

例如仪器读数系统性偏大 12 cm⁻¹，就设 `XSHIFT=-12`，图上峰位会整体减小 12。

轴范围始终是 XMIN–XMAX。也就是说校正只改变「这个峰被标成多少」，不会改变「看的是哪一段数据」——脚本会自动把取数窗口反向补偿。

`out\peaks.csv` 里带一列 `shift_cm-1`，记录本次用的校正量，方便回溯。

## 峰高 H 的定义

```
H = I_max - I_baseline
```

- `I_max`：峰顶处的实测强度
- `I_baseline`：峰两侧 ±60 cm⁻¹ 范围内两个局部极小值中**较高**的那个

这是从数据本身估出来的背景，不是仪器测的基线。所以 H 只适合在同一批数据内部比较峰的高低，不要当成绝对强度。

只有 `H >= HEIGHT` 的峰才会标注波数。峰位由高斯 + 线性基线拟合给出，拟合窗口 ±30 cm⁻¹。

## 输出

- 单谱模式：`out\<文件名>.png`，每份 txt 一张，2048×1024
- 单谱模式：`out\peaks.csv`，峰位表，列为 文件、峰位、H、I_max、I_baseline、校正量
- 堆叠模式：`out\stack.png`，一张对比图

图片先写成临时文件再替换过去，所以不会出现写了一半的残图。如果某个文件被占用（比如图片还开着），会自动重试三次；仍然失败的话只跳过这一个文件，其余照常出图，并在窗口里列出失败的文件名。

## 速度

两种模式都是按文件并行出图：每个 txt 的读取、找峰、画单图在一个子进程里一次做完，合并图复用同一批结果，不重算。

- 26 条谱：堆叠模式约 1.8 s，单谱模式约 1.6 s（16 核机器实测，含进程启动）
- 少于 5 条谱或只有单核时自动走串行，避免进程启动开销超过收益
- 进程池起不来（受限环境）会静默退回串行，不会导致出图失败

## 单独改参数运行

不想用 bat 的话，可以直接命令行：

```
python plot_raman.py --xmin 200 --xmax 1200 --height 80 --shift -12
python plot_raman.py --stack stack.xlsx
```

`--src` 和 `--out` 可以指定别的输入输出目录；`--stack` 后面跟表格路径，此时 `--xmin/--xmax` 可省略，写了会覆盖表格里的区间。

## 出错时

窗口里出现 `FAILED <文件名>: ...` 表示那一个文件没写出来，其余的都正常。常见原因：

- 图片正在看图软件或 PPT 里开着 → 关掉后重跑
- 杀毒软件或网盘同步正在占用 `out` 文件夹 → 等一会儿重跑，或先把 `out` 移出同步目录

脚本会自动重试三次，多数临时占用能自己恢复。
