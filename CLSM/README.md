# CLSM 多位置平均剖面槽深与开口宽度

把共聚焦ASCII矩阵放入 `data/3d/`，双击 `run_clsm.bat`。继续使用项目共用的 `../python/python.exe`，无需修改Conda或安装依赖。

运行所需文件均在本模块内：`extract_groove.py` 为主入口，`profile_measurement.py` 为平均剖面计算模块，`surface_plots.py` 为2D/3D绘图模块，三个脚本保持同目录；`run_clsm.bat` 为启动脚本。正式数据放入 `data/3d/`，最新结果、方法说明和验证记录在 `out/paper_v4/`，`out/` 只保留本次运行结果，不作为长期备份目录。本模块不依赖 Codex 工作区中的临时过程目录。

六份现有文件均为CMP后数据，1–6激光功率递增；CMP前槽深未保存。因此测量结果是剩余槽深，不能恢复绝对去除量。初始槽宽相同不等于初始槽深相同。

## 主方法

本版本结合文献的“多位置测量”和“平均剖面”思路，采用 **先平均高度剖面、再测槽深、最后汇总固定位置** 的顺序。它与旧版“各列先取最深值、最后取空间中位数”是不同的测量定义。不是某一篇论文完整算法的复刻，也不通过调整位置或参数追求1–6单调。

1. 在每幅扫描图的X范围25%、50%、75%处，选择离目标位置最近的列。这里是扫描视场位置，不能证明等于整条实际参考槽长的这些位置。
2. 每处取请求宽度12.6µm的条带。本批每条带实际包含21列，首末列中心跨度12.50µm。按实际X间距的 `gradient(X)` 加权平均高度；等间距时等于算术平均。导出坐标的0.62/0.63µm交替不需要重采样。
3. 仅使用清理后的真实支撑点，缺失、插值和修复点不参与条带平均；每个Y行至少80%的列和空间权重有效。保留支撑数、比例和X权重。为数值滤波补齐的行不得冒充真实支撑；槽底搜索区和拟合槽口需要真实支撑检查。
4. 对条带平均轮廓，在距公共槽心70–165像素的两侧平台稳健拟合二次基准面；至少各15个真实平台行。减去基准后做3像素轻度平滑，在±45像素内找槽底，并做三点抛物线修正。
5. 槽深为基准面到平均轮廓最低处的高度差；不是槽底平台所有像素的平均高度。平台噪声从未平滑的条带平均残差估计；小于0.10µm、低于5倍噪声、搜索边界或真实支撑不足时，保留候选值与无效原因。
6. **三个固定位置全部通过深度检查，才输出三位置算术平均值及位置间标准差。** 不把较浅或未检出位置剔除后，静默平均剩余位置。部分位置均值仅保留在JSON审计的辅助字段中。

没有按最低点平移配准剖面，保持仪器Y坐标；条带内槽底位置变化超过3像素时标记平均轮廓可能展宽。默认滤波窗、条带宽、噪声阈值、基准区与质量规则均是本项目操作参数，不宣称是统一标准或经实物标定的最佳值。

开口仍使用持续凹陷与浅壁线性/陡壁连续折线外推至基准面的定义，但输入为新的条带平均剖面；有效性独立于深度。三个开口全部有效才输出新方法开口均值。1号当前只有2/3处开口通过，故均值留空，而3/3处深度均保留。

同时输出开口内凹陷截面积A和等效截面平均深度A/W；面积只在槽深、开口和内部真实支撑均通过时计算。A/W包含槽壁贡献，不是最大槽深，也不是完整三维槽体积的V/(WL)。本批完整槽体积没有计算。

## 2D与3D形貌图

正常运行 `run_clsm.bat` 时，除原有测量与诊断图外，还会生成：

- `out/2D/原文件名.png`：完整矩阵的俯视高度图。
- `out/3D/原文件名.png`：参考地形表面样式的斜视三维图，含X/Y/Z坐标及高度色标。
- `out/surface_plot_manifest.json`：输入/图像哈希、坐标和色标范围、缺失点数量、显示采样及视角记录。

两种图均使用导出的原始Z高度，恢复缺失掩码后留空；不额外平滑、去倾斜、按最小高度归零或替换异常深区。每个样品的2D/3D共用色标，不同样品色标范围按自身真实高度确定，不能仅凭相同颜色比较组间高度。Z高度不是计算出的剩余槽深。

3D为便于查看使用纵向显示夸张30倍，轴刻度仍为真实µm，图下注明；表面仅每2个像素取原节点显示，保留末行末列，不对高度插值。2D使用完整矩阵（本批为512×512）。3D显示抽样可能遗漏细小结构，不用于替代完整矩阵的定量计算。Y坐标继续遵循 `--dy` 或原步距假设，图下注明。

图像为300 dpi PNG。只更新2D/3D、不重写Excel及测量结果时，可运行：

```powershell
..\python\python.exe -B .\surface_plots.py
..\python\python.exe -B .\surface_plots.py --dy 0.63
```

`--no-plot` 会跳过所有图像导出。主脚本指定 `--out 自定义目录` 时，测量结果写入该目录，形貌图写入其 `2D/`、`3D/` 子目录；独立绘图脚本的 `--out` 也是图像根目录。

## 对照与敏感性

- 原v3逐列深度中位数、分位数、异常候选及v2逐列开口完整保留作对照；其数据处理定义不变。
- 固定默认位置，将条带宽度减半/加倍，基准改为线性或外移至90–180像素，平滑改1/5像素，比较方法敏感性。
- 固定条带宽度，将三个位置整体前移或后移图幅的5%，检查空间取样敏感性；这些是预设变化，不挑选更单调的一组作为结果。
- 另给出中央80%图幅的单个平均剖面作覆盖范围对照，以及零值作为真实高度的敏感性。

原缺失、孤立尖点规则保留；零值缺失假设尚待仪器信息确认。连续深区不按编号趋势删除。所有这些比较都是同一幅图的数据再处理，不是独立重复实验；三位置SD也是空间差异，不是3次独立试验的误差或95%置信区间。

## 输出与运行

默认测量输出为 `out/paper_v4/`，形貌图输出为 `out/2D/` 和 `out/3D/`。

每次运行 `run_clsm.bat`，输入成功处理后、写入本次结果前，自动清空本模块整个 `out/`，包含旧图、Excel、旧版本目录、审计记录和其中的备份，然后重新生成本次输出。`data/`、代码及模块根目录下的文件不清理。需长期保留的结果请存放在 `out/` 外；`--out` 位于本模块 `out/` 外时，外部目录不会自动清空。

输入无效、没有可处理数据时不清理。清理前检查目录边界、链接、只读及文件占用；发现异常则报错并停止写入本次结果，请先关闭占用结果文件的Excel再重试。不要在分析运行期间编辑或打开正在生成的结果。

`--help` 和 `--selftest` 不清理、不写入结果。直接运行Python主脚本保持原有行为，只有显式指定 `--clean-out` 才清空 `out/`；独立运行 `surface_plots.py` 仍只更新图像，不执行整目录清理。

- `groove_paper_results.xlsx`：第一页“核心结论”仅列各样品剩余槽深均值、位置间SD和开口宽度均值，直接引用第二页“槽宽槽深汇总”。完整汇总、旧逐列明细、CMP前后对照，以及平均剖面明细、逐Y数据和敏感性均保留。首页空白表示固定位置未全部有效，不显示为零。
- `*-3d.png`：三处条带位置、平均剖面与基准支撑、与整图深度分布关系、各位置数值。
- `depth_comparison.png`：新旧深度、中央80%辅助值、条带/基准/取样位置敏感性。
- `paper_profile_audit.json`：全部主剖面、X权重、每行真实支撑、基准系数、候选值、无效原因、参数和文献DOI。
- `depth_audit.json`、`*_quality_masks.npz`：原逐列审计、缺失与修复追溯。
- `run_manifest.json`：脚本与新模块SHA256、输入哈希、主结果及参数。
- 历次验证记录随旧 `out/` 一起清理；当前运行的参数、输入哈希和结果以本次 `run_manifest.json`、剖面审计及形貌图记录为准。

```powershell
.\run_clsm.bat --selftest
.\run_clsm.bat --no-plot
.\run_clsm.bat --out out\paper_v4_run2
.\run_clsm.bat --strip-width-um 12.6
.\run_clsm.bat --profile-positions 0.25 0.50 0.75
.\run_clsm.bat --dy 0.63
```

位置是图幅比例，须3个严格递增的0–1数值，条带不可重叠。宽度单位为µm；`--dy`仍指真实Y步距。原文件缺少Y标定，默认Y步距按X中位步长假定，本批0.63µm；影响开口与面积，不直接缩放深度Z。平均条带按X坐标取样，不受Y步距假设影响。

CMP前后对照页使用新方法槽深，CMP前输入及差值保持空白。即使以后补录初始深度，也须保持前后测量定义、位置与标定可比；槽深变化只有在参考槽底稳定时才等于表面去除厚度。

## 文献依据

- Materials 2023,16,4761，DOI `10.3390/ma16134761`：在槽长1/4、1/2、3/4附近多位置测量后平均。这里借用多位置思路，不声称复刻原文12次测量。
- Scientific Reports，DOI `10.1038/s41598-024-81233-0`：从共聚焦三维数据提取槽中部平均剖面。
- Journal of Materials Research and Technology 2026,41,2775–2789，DOI `10.1016/j.jmrt.2026.01.163`：以两侧表面与槽底的相对高度讨论CMP残余划痕深度；分别测量槽深变化与材料去除深度。
- Materials 2023,16,2536，DOI `10.3390/ma16062536`：V/(WL)等效平均深度。当前仅增加截面A/W辅助量，没有把三处截面积冒充完整槽体积。
