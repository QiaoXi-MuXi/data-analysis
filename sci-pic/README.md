# SCI 科研绘图模板

## 桌面使用：先看样式，再填数据

双击项目根目录 `DataAnalysis.exe`，在左侧选择 **sci-pic 科研绘图**，或从概览页进入。缩略图和大图展示两种模板的真实出图样式：柱状折线图、双组对比柱状图。预览为固定示例，实际数据和设置以生成时保存的工作簿为准。

1. 选择样式，点击“填写数据”。首次会在 `out/workbooks/` 创建唯一 Excel 工作副本并打开，模板本身保留。
2. 修改副本中的“数据”“设置”两张表并保存。也可用“选择已填工作簿”加载已有副本；工作簿图类型须与所选模板一致。
3. 点击“生成图片”。结果页自动显示本次 PNG，也可预览 PDF、SVG、输入快照和运行记录。后台运行时可切换其他项目。
4. GUI 每次在结果父目录下建立 `runs/时间戳_编号/`，包含冻结的 `input.xlsx`、`run.json` 和 `results/`；源工作簿只读。通过运行记录可重新打开历史产物。

```text
sci-pic/
  templates/             sci_pic.xlsx、removal_rate.xlsx 两个 Excel 模板
  previews/              roughness.png、removal_rate.png 两张样式示例
    manifest.json        预览来源与脚本 SHA256
    references/          原有参考图，不作为可生成模板展示
  templates.json         模板、工作簿、预览与说明的对应关系
  plot_sci_pic.py         共用绘图引擎
  build_previews.py       根据当前模板更新预览
  run.bat                默认柱状折线入口
  主张折线图.bat          保留已有名称，转交 run.bat
  去除率绘图.cmd          双组对比入口
  out/                   工作副本和独立结果
```

原工作簿迁移到 `templates/`，旧结果保留在 `out/`。已打开的工作台需正常退出后重新启动才能加载新增页面；EXE 会加载同级 GUI 源码，无需重新安装。

维护预览时，在项目根目录执行 `./python/python.exe -I -B -X utf8 ./sci-pic/build_previews.py`。程序使用现有绘图引擎生成预览和来源摘要；预览不会随用户副本自动变化。

## 去除率双组对比模板（2026-11-04）

1. 打开 `templates/removal_rate.xlsx`，在“数据”表 A5:B6 修改组名和数值；第一行为基准组，第二行为实验组。
2. 按需在“设置”表修改指标名称、单位、配色、尺寸、数值精度及倍数开关，保存并关闭 Excel。
3. 双击 `去除率绘图.cmd`。该入口转交现有 `run.bat`，共用同一个绘图程序；每次结果保存在 `out/时间戳_编号/`。

模板预填截图中的去除率：无激光基准组 **304.2 nm/h**、有激光实验组 **1573.8 nm/h**。采用浅蓝/深蓝双柱、从零起始的纵轴、柱顶原值标注；两柱之间的竖向箭头从基准组高度指向实验组高度，箭头旁显示“实验组/基准组”的 **5.17×**。这是数值比值，不是显著性标记；没有重复测量或不确定度数据，因此不添加误差棒。图中不使用折线连接两种离散条件。

“数据”表右侧公式显示倍数和相对增幅（当前为 417.4%），不参与数据读取；绘图时直接从两组原值重新计算倍数。默认尺寸 12.5 × 11.0 cm，PNG 为 300 dpi，另存 PDF/SVG 矢量图。每次保留完整输入快照、数据 CSV、配置、来源/脚本 SHA256 和运行记录，不覆盖旧结果。

“双组柱状”模式仅接受恰好两组非负数值；基准为零时关闭“显示倍数”即可绘图。组名与数值必须同时填写，单位需保持一致，不自动转换、拟合、平滑或推断统计显著性。Excel 中的公式不能用作 A/B 列输入值。

```powershell
.\去除率绘图.cmd --check
.\去除率绘图.cmd
.\run.bat --excel .\templates\removal_rate.xlsx
```

原有 `templates/sci_pic.xlsx` 和无参数 `run.bat` 仍使用下述柱状折线模板。新参数为可选项：`图类型`（柱状折线/双组柱状）、`显示倍数`（是/否）、`倍数小数位数`（0～6）；省略时保留原行为。新增 `paired` 配色可用于双组柱状图，原 `academic`、`npg` 配色继续可用。

## 填写规则

- 保留两张表的名称、第 4 行表头及“设置”表 A 列参数名，只修改输入区域。
- 类别与数值必须同时填写。A、B 两格都为空的行会跳过；零值会保留。C 列仅作备注，不参与绘图。
- 数据可以超过预留的浅黄色行，直接在表尾追加即可；程序会按原顺序读取，不排序、不合并相同类别。
- 请填写实际数值；不接受公式、Excel 错误值、NaN 或无穷大。从其他表复制时，可使用“选择性粘贴 → 数值”。
- 样本较多时可增大图片宽度，类别较长时可调整“标签旋转_度”或在单元格内手动换行。
- 数值标签的“小数位数”只影响显示；原始数值在输出 CSV 和运行记录中保留，不做单位转换、拟合、平滑或插值。

## 样式

保留单系列柱状叠加折线、同一纵轴、无背景网格、三位小数标注。两种模板统一使用四边闭合坐标轴框，上下左右边框均显示，线宽 0.7 pt、颜色 #333333；刻度和标签仍沿用左侧与底部设置。英文及数值采用 Arial，中文采用微软雅黑；PDF 嵌入 TrueType 字体，SVG 保留文字。纵轴覆盖零和所有数据，支持负值。

- `academic`：沿用 `academic-paper` 可视化模块中的 Tol 分类色板，青蓝 `#33BBEE` 柱形、深蓝 `#0077BB` 折线。
- `npg`：蓝色 `#4DBBD5` 柱形、珊瑚红 `#E64B35` 折线，是可选配色，不代表 Nature 唯一制图规范。

默认宽 17.5 cm、高 11.4 cm、PNG 600 dpi；同时输出 PDF、SVG。默认不显示图内标题。未提供重复测量和不确定度时不生成误差棒，不作显著性或机理判断。该模式支持一组数值的柱状折线组合图；两条件对比可使用上面的双组柱状模板。

## 每次运行保留的文件

| 文件 | 内容 |
|---|---|
| `图名.png` / `.pdf` / `.svg` | 本次图形，文件名来自“设置”表 |
| `input_snapshot.xlsx` | 本次实际读取的完整输入工作簿副本 |
| `data_used.csv` | 原 Excel 行号、类别和数值 |
| `run_info.json` | 实际配置、源文件 SHA256、依赖版本和绘图对象核对结果 |

失败时显示具体问题；若绘图阶段已产生文件，会在该运行目录写入 `FAILED.txt`，保留现场，不清理旧结果。

## 命令行

```powershell
.\run.bat --check
.\run.bat --excel "D:\实验\新数据.xlsx"
.\run.bat --excel "D:\实验\新数据.xlsx" --out "D:\实验\论文图"
```

相对的 `--excel`、`--out` 路径相对于调用终端的当前目录；无参数时固定读取本模块的 `templates/sci_pic.xlsx`，写入本模块的 `out/`。双击无参数运行成功后打开 `out/`。

## 环境与边界

使用项目同级 `../python/python.exe`，依赖现有的 matplotlib、numpy、openpyxl、Pillow。无需 Conda，不安装或升级依赖；缺少共享解释器会停止，不回退系统 Python。保留整个项目目录即可迁移。

BAT 使用 GBK 兼容编码和 CRLF，运行时排除用户包、继承的 `PYTHONPATH` / `PYTHONHOME` 及字节码缓存。自动化可设置仅影响当前进程的 `DATA_ANALYSIS_NO_PAUSE=1`、`DATA_ANALYSIS_NO_OPEN=1`，分别禁用失败暂停与成功后打开目录。

程序只读原工作簿。Windows Excel/WPS 的实际编辑界面及其他机器字体环境尚需自行确认；Excel 文件打开时请先保存，程序只能读取磁盘上已保存的数据。本模块已接入桌面工作台，支持模板样式预览与工作副本出图。
