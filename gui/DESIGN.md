# 工作台界面设计规范

本文件记录 `gui/` 已经在用的设计语言。数值都落在 [`theme.py`](theme.py) 的颜色与字号常量里，
布局数值留在 `app.py` / `editor.py`。改界面时先改 `theme.py`，不要在页面里写新的十六进制颜色。

规范来源：Atrium Desktop 设置中心（`docs/DESIGN.md` 第 8 节）。它把一个设置窗口拆成
“顶栏 + 三列（侧边栏 / 工作区 / 检查器）”，用中性灰底、白色卡片和唯一强调色把层级交给留白，
而不是交给颜色。工作台沿用了这套结构，去掉玻璃材质与弹簧动画这类桌面环境专属的部分。

## 1. 色彩

| 用途 | 值 | 说明 |
| --- | --- | --- |
| 工作区底色 | `#F5F5F7` | 只有底，不参与层级 |
| 卡片 / 侧边栏 | `#FFFFFF` | 与底色相差一档，靠 1 DIP 描边收边 |
| 描边 | `#E1E1E6` | 卡片外框；表内分隔线用 `#EDEDF0` |
| 主文字 | `#111317` | 标题、行标题、数值 |
| 次文字 | `#5F5F66` | 说明、正文 |
| 弱文字 | `#8A8A92` | 表头、脚注、占位 |
| 强调色 | `#0A84FF` | 唯一彩色：选中项、主按钮、勾选、焦点 |
| 强调浅底 | `#EAF3FF` | 选中行、状态标签、小按钮 |
| 警示 | `#E0352B` | 只用于必现错误 |
| 未保存 | `#F0A020` | 只用于“● 未保存修改”状态点 |

一条规则：**同一屏只允许一个强调色的实心块**。主按钮与选中的侧边栏项不会同时出现，
所以“开始分析”永远是视觉终点；“保存项目”在未保存时才变成强调色，保存后自动退回次要按钮。

## 2. 字号阶梯（一个页面最多三档）

| 档位 | 字号 | 用在哪里 |
| --- | --- | --- |
| 页标题 | 28 / 600 | 项目标题、概览大标题 |
| 卡片标题 | 19 / 600 | 卡片内的标题 |
| 分组 / 行 | 14 / 600 | 分组框标题、检查器里的样本名 |
| 正文 | 13 | 正文、说明句 |
| 脚注 | 11.5 / 600 | 表头、eyebrow、脚注 |

中文不使用全大写或字距拉伸；`eyebrow` 只放英文模块代号并加 1.4px 字距。

## 3. 圆角与间距

| 元素 | 圆角 |
| --- | --- |
| 卡片、分组框 | 18 |
| 内嵌预览、列表项 | 12 |
| 输入框 | 8 |
| 按钮、胶囊 | 高度的一半（15–16） |
| 侧边栏选中项 | 19（行高 38 的胶囊） |

间距刻度只用 4 / 8 / 12 / 16 / 20 / 24 / 28。卡片内边距 18，页面边距 28。
嵌套时内层圆角取 `外层 − 间距`，最小 6，保证角落同心。

## 4. 控件

- **侧边栏**：宽 232，行高 38、圆角 19；选中项是强调色胶囊 + 白字，未选中悬停是 `#F1F1F4`。
- **标签页**：胶囊分段而不是下划线。未选中 `#F0F0F3` 淡灰底，选中强调色实心（同一时刻只有一个实心块）。
- **检查器**：宽 240–340，只有一条 1 DIP 左分隔线，**不做成卡片**；参数是裸行，标签在数值上方。
- **表格**：白底、无圆角、无竖线；只有 1 DIP 横向分隔线；表头 11.5px 弱文字、左对齐（勾选列居中）。
- **下拉框**：右侧留 26 DIP 给独立箭头（`assets/chevron-down.svg`，10×10 弱灰），外观必须与输入框区分；滚轮不改值（`WheelGuard` 把滚轮事件转给最近的滚动区），只有点击、键盘或焦点内的明确操作才切换。
- **勾选列**：18 DIP 圆角方块，选中为强调色实心 + 白色勾（`TypedDelegate.paint_check`），不用系统默认指示器。
- **产物路径行**：只读路径框与“打开 / 文件夹”同排（按钮固定 64 宽），路径不存在时按钮禁用而不是点了没反应；生成产物后立刻把入口点亮，并给完整路径 tooltip。路径框显示时把光标归零，长路径从根目录读起而不是只剩文件名。
- **最近记录**：产物类页面给一个“最近副本”菜单按钮（不用下拉框，避免长期占宽），条目按使用时间倒序、去重、最多 8 条，末尾附“打开所在目录”。
- **滚动条**：轨道透明，滑块 3–4 DIP 圆角细线，悬停加深。
- **日志**：`#1C1C1E` 深底等宽字，圆角 12；只用于运行日志和检查输出，不用于正文。

## 5. 状态与交互

- **未保存**：页脚显示“● 未保存修改”，保存按钮同时变成强调色实心；保存后回到“无未保存修改”，按钮退回次要样式。
  不靠按钮文案加星号。
- **输入检查**：通过时是弱文字，发现问题转为警示色并给出“查看问题（N）”。
- **焦点**：所有按钮与输入框保留 2 DIP 强调色焦点框，Tab 顺序按阅读顺序。
- **忙碌**：进度条只有 3 DIP 高，不用百分比；运行中按钮置灰而不是换成假进度。
- **窄窗口**：页面整体横向滚动，检查器不被裁掉；卡片里的说明文字保底 170 DIP 宽，不竖排挤成一列。

## 6. 与 Atrium 有意不同的地方

| Atrium | 工作台 | 原因 |
| --- | --- | --- |
| 侧边栏 Mica 材质 | 纯白 + 右描边 | Qt 窗口没有 Mica；纯白在浅灰底上已经能分层 |
| 弹簧/缓动动画 | 无过渡 | 分析页切换时会重扫目录，动画只会掩盖卡顿 |
| 工作区 < 900 时检查器折到下方 | 横向滚动 | 折行会打乱四段式页面的阅读顺序 |
| 44×26 拨动开关 | 18×18 勾选框 | 表格里的启用列需要和表单里的布尔项同一种标记 |
