# Data Analysis 原生桌面工作台

双击根目录 `DataAnalysis.exe` 打开 Windows 原生 PySide6 窗口，无控制台弹出，应用与任务栏使用统一图标。共享便携 Python，无需浏览器、账户或服务。重复启动会切回已打开的新版窗口。旧 `run_gui.bat` 转交同一EXE，保留终端 `--check` 诊断。

## 使用流程

1. 在左侧选择 Ra、Raman、CLSM、ER 或 sci-pic 科研绘图。
2. Ra/Raman 首次读取原有 Excel。双击表格修改，或选中样本后在右侧参数面板编辑；支持多选后批量设置、启用/停用、排序、搜索及撤销/重做。输入检查自动列出缺失文件与配置问题，点击问题可定位样本，也可手动重新检查外部文件变化。BMP 的 DAT 专属参数正常时不可编辑；若旧表带有非法值，允许修正或清空以通过原引擎校验。
3. “添加文件”或运行设置中的追加操作只添加新样本，保留原有参数和缺失行；移除配置行不删除源文件。右侧源文件的“选择…”可重新指定路径并保留本行参数，支持撤销。导入配置支持 JSON、XLSX 和 UTF-8 CSV，不回写来源工作簿。
4. 点击“保存项目”或 Ctrl+S。默认保存在根目录 `out/gui/projects/模块.json`；另存为需要新文件名。JSON 保存样本、全局参数、原配置额外列和相对路径；CSV 用于交换样本表，导出源文件为绝对路径，不包含全部项目设置。CLSM/ER 的项目保存全局运行参数。
5. 在“运行设置”核对输入、输出父目录及参数。开始分析前保存修改；非法值、重复输出名和启用的缺失输入会拦截运行。Raman 单谱需填写波数上下限，堆叠模式保留原模块的共享区间与统一归一化约束。
6. 四模块均在“运行设置”调整参数，输入页与结果页保留完整工作区。ER输入列表选中票据可直接预览图片或PDF，PDF支持页码跳转和上一页/下一页。运行时可切换项目，日志默认折叠，失败时展开。完成后在结果页查看本次产物，或从运行记录重新打开历史结果与日志。

## 科研绘图样式预览

在左侧或概览页进入“科研绘图”，先看柱状折线图、双组对比柱状图的缩略图与大图示例，再点击“填写数据”创建并打开 Excel 工作副本。保存后点击“生成图片”，后台调用同一绘图引擎导出 PNG/PDF/SVG，在结果页直接查看；也可选择已有工作簿，或从运行记录查看历史结果。

模板位于 `sci-pic/templates/`，预览位于 `sci-pic/previews/`，对应关系由 `sci-pic/templates.json` 管理。预览展示固定示例，实际数据和设置以保存后的工作簿为准。工作副本位于 `sci-pic/out/workbooks/`；每次生成在结果父目录的 `runs/` 下独立保存输入快照、运行清单、日志及实际产物。详细填写规则见 `sci-pic/README.md`。

当前 EXE 从同级 `gui/app.py` 加载新增页面；已打开的旧窗口需要正常关闭后重新启动。不需要新依赖或重新构建启动器。

## Ra 一键配置与数值标注

在 Ra 的“样本与配置”点击“一键配置”（下方“批量设置”也打开同一窗口），选择全部 `.bmp`、全部 `.dat`、全部图片、所选行或全部样本。后缀大小写无关；后缀范围包含停用行，与当前搜索筛选无关。勾选需要修改的字段后点击“应用到 N 行”，仅修改勾选项，整次操作可一次撤销。

- “常用标注样式”：勾选并填入启用、32 px、白字、左上、2 px 黑描边；仍需点击应用。
- “关闭附加标注”：只改标注开关，保留其他样式和计算参数。“恢复标注默认”将六项标注设置清空为模块默认。
- 可逐行或批量调整字号（8–96 输出像素）、`#RRGGBB` 颜色及选色器、四角位置、描边宽度（0–8 px，0表示无描边）及描边颜色。预览仅使用示意值，实际数值由分析产生；较大字号会占用更多绘图区。
- 空值/旧项目兼容默认：BMP/图片标注启用，DAT附加标注关闭；字号44、白色、左上、3 px黑描边。BMP使用截图Ra及原单位，DAT启用后显示本次处理后面的Sa（nm），独立图与四联图中的斜视图一致。关闭只隐藏附加数值，不移除原图内的坐标、图框或仪器字段；数值统计不受影响。
- 右上角“导出 / 另存为 → Excel 配置（含标注设置）”新建含六个标注列的XLSX，保留停用行；颜色填写色号，不使用单元格字体颜色。修改Excel保存后，通过“导入配置”重新载入，再保存项目并运行。也可用 `Ra/run.bat --config 配置路径` 直接运行。CSV/JSON和每次运行的快照同样保留标注参数。
- 导出不会覆盖已有文件或来源Excel；交换表包含标准样本参数，额外备注和完整运行设置仍保存在JSON项目中。原 `fill_config.bat` 再次导入旧表时会在写前备份并补充标注列；正常分析不写入输入表。
- 这些参数仅对“样本配置”运行模式生效；目录扫描使用原默认样式。修改后按Ctrl+S保存，再开始分析，已有历史图片不会随草稿变化而重绘。运行清单保存实际采用的 `label_style`。

## 保存、运行与数据保护

- 修改后的项目先写临时文件再替换，更新前备份至项目文件同级 `.backups/`。外部修改冲突时拒绝覆盖，窗口草稿保留。表格撤销仅针对样本编辑，全局运行设置直接保存。
- 无效数值保留为待修正草稿，保存和运行会提示；不会悄悄采用旧值。项目可以保存缺失/全停用样本，运行前必须修正或停用缺失输入并至少启用一份样本。
- 每次 GUI 运行建立独立 `runs/时间戳_编号/`，其中 `project.json` 是冻结项目，Ra/Raman 另有兼容引擎的 `config.xlsx`，`run.json` 记录输入 SHA256、参数、退出码和实际产物，结果位于 `results/`。Ra/ER 的默认输出父目录为模块 `out/`，Raman/CLSM 为其选定输出目录。
- 运行记录索引和日志位于根目录 `out/gui/history/`、`out/gui/logs/`。历史列表最多200次；旧命令行结果不自动纳入。移动或删除历史输出后可能无法打开，请保留对应目录。
- 运行结束会复核输入摘要，输入变化则标记“需复核”。准备和归档时使用忙碌状态，不显示虚假的百分比。同模块同时只运行一项，运行中禁止关闭；当前未提供取消任务。
- 原科学代码、原始输入、来源 Excel 和既有结果不由配置编辑改写；GUI不传 CLSM `--clean-out`。原 BAT 的结果位置、清理及配置同步行为保留。
- 配置 Excel 导入最多20000行、256列，不计算公式；公式保留为需修正的原值。结果工作簿预览只读缓存值，最多200行、40列；文本预览最多256KB。结果/输入可视列表最多2000份。
- PDF预览在本机只读渲染，每次加载一页，限制64MB和图像长边1800像素；超限、加密或损坏文件可外部打开。此处不修改票据、不编辑OCR内容，品名和金额仍需人工检查。CLSM槽宽、LSM高度标定、Ra候选去噪的科学限制沿用各模块文档。
- 输入检查与实际保存/运行共用配置规则；问题列表最多展示100项。检查通过表示当时的文件及参数可用，不代表科学准确性，开始分析前仍会复核。目录扫描模式不使用样本表。

## 验证与维护

```powershell
.\run_gui.bat --check
.\check.bat --no-pause
.\python\python.exe -I -B -X utf8 -m unittest discover -s .\gui\tests -v
```

使用现有 `python/requirements-gui.txt`，本次未新增或升级依赖。正常启动仅检查依赖，不自动安装或下载；新机器需复制完整项目和共享便携 Python。

`DataAnalysis.exe`为轻量启动器，始终从自身所在目录查找 `python/python.exe`、`python/pythonw.exe`、`gui/app.py`，从其他当前目录运行也可使用；无需管理员权限。缺文件或依赖失败时显示中文错误并记录 `out/gui/launcher_error.log`，启动检查结果位于 `out/gui/startup_check.log`。便携分发请复制整个项目目录。启动器源码、图标及重建说明见 [launcher/README.md](launcher/README.md)。

`app.py` 负责窗口、预览和后台进程；`sci_pic.py` 负责科研绘图模板目录、工作副本和运行快照；`editor.py` 负责原生配置控件；`documents.py` 负责导入、校验及保护保存；`pdf_preview.py` 负责有内存上限且串行执行的PDF渲染；`runs.py` 负责运行快照与归档；`model.py` 保留CLI适配；`theme.py` 统一样式。单实例锁位于 `out/gui/workspace.lock`，启动检查和异常日志位于同目录。分析进程按参数数组启动，不拼接Shell；输出按UTF-8解码，耗时工作在后台执行。
