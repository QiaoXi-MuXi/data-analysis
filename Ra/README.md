# Zygo BMP / DAT 粗糙度分析

## 快速使用

| 项目 | 说明 |
|---|---|
| 输入 | 截图 BMP/图片或 Zygo DAT；由 `ra_config.xlsx` 的启用行控制。 |
| 配置 | `ra_config.xlsx`；`fill_config.bat` 默认使配置行与当前 `data/` 对齐，旧目录的配置行会移除，写前备份。 |
| 运行 | 双击本目录唯一的 `run.bat`，参数原样传递。 |
| 输出 | `ra_results.xlsx`、`out/bmp/`、`out/dat/`。 |
| 环境检查 | 运行根目录 `check.bat`；使用共享 `../python/python.exe`，不回退系统 Python。 |

命令行无人值守运行可在当前 PowerShell 设置 `$env:DATA_ANALYSIS_NO_PAUSE='1'`，使失败时直接返回退出码；该设置不取消 Raman 无参数单谱模式的输入提示。检查后可用 `Remove-Item Env:DATA_ANALYSIS_NO_PAUSE` 移除。原始输入及现有输出位置保持原有约定。

与 Raman/stack.xlsx 一样，使用**独立配置 Excel 驱动运行**：

`ra_config.xlsx → run.bat → ra_results.xlsx + out/`

修改 `ra_config.xlsx`，保存后双击 `run.bat`，自动处理表中全部启用行，不再询问每区张数。运行只读配置，不把配置写回结果表，不会自动把data的新文件加入本次输入。

新增文件放入data后，双击 `fill_config.bat` 导入配置：新BMP/图片的DAT去噪列默认0，新DAT默认1，高通默认关闭。默认按当前data重建文件行集合，移除不在该目录的旧行，保留当前文件的已有参数；写入前自动备份配置。导入后可在Excel中逐行修改0/1，保存关闭后再运行 `run.bat`。

## 配置表

`ra_config.xlsx` 第一张“配置”表控制处理；第二张“说明”表解释各列。每行可以填一个BMP截图或DAT原始文件，两类独立统计。同一张表可同时指定data内和外部目录的文件。

| 列 | 作用 |
|---|---|
| 文件 | 必填。绝对路径，或相对本配置文件的路径；只填文件名时先找配置同目录，再找data/。 |
| 启用(0/1) | 1处理、0跳过；空值按1。停用行可以保留暂时不存在的文件。 |
| 区域 | 自定义分组；空值按文件名前缀（如3-4属于3）分组；无法匹配时每5个一组。 |
| 输出名 | 空值沿用源文件名（不含扩展名）。不同目录同名文件可设不同输出名，避免覆盖；不要带路径。 |
| DAT去噪(0/1) | 新导入DAT默认1、BMP/图片默认0；空值也按文件类型。已填0/1优先，仅对DAT生效。 |
| 高通方式 | 关闭 / 自然样条候选 / 高斯候选；空值关闭，仅对DAT生效。 |
| 截止波长(µm) | 正数，空值80；高通开启时使用。 |
| 四联图(0/1) | DAT完整四联图开关，空值按1；BMP不生成四联图。 |
| 独立图(0/1) | BMP裁图或DAT独立Oblique图开关，空值按1。 |
| 数值标注(0/1) | 1添加数值、0关闭附加标注；空值或缺列按旧效果：BMP/图片启用、DAT关闭。 |
| 标注字号(px) | 8–96整数，默认44；单位是输出图像像素。字号超出图宽时会自动收敛到能完整放下的尺寸，不裁字。 |
| 标注颜色 | `#RRGGBB`，默认 `#FFFFFF` 白色；填写色号，不读取Excel单元格字体颜色。 |
| 标注位置 | 左上 / 上方中间 / 右上 / 左下 / 下方中间 / 右下，默认左上；`上方中间`为水平居中贴顶，`下方中间`为水平居中贴底。 |
| 描边宽度(px) | 0–8整数，默认3；0不画描边。 |
| 描边颜色 | `#RRGGBB`，默认 `#000000` 黑色。 |

注意：

- 列顺序可以调整，按表头识别；支持file/enabled/group/stem/denoise/highpass/cutoff/combined/single等英文别名。空行跳过，可以添加备注列。
- 开关可以用0/1或启用/关闭；填写实际值，不使用公式。
- 只处理启用的行，行顺序沿用表格；不再从结果表读取任何处理参数。
- 关闭两种出图仍参与数值统计和min/medoid选择；某代表样本未启用某类出图时，该类别没有它的副本。
- 参数非法、同类型输出名重复、文件不存在时停止并指出行号，不静默使用默认配置。
- 处理期间若配置、源数据或结果表被修改，停止写入，避免覆盖新的编辑。结果表无法读写时会显示中文提示：请保存并关闭 Excel / WPS 中的 `ra_results.xlsx` 后重新运行；若已关闭，检查只读属性及输出目录写入权限。程序不会自动关闭 Excel 或丢弃编辑。

实际处理范围以当前配置表的启用行为准。默认导入后只保留当前data中的文件行；如需处理外部DAT，请显式导入对应目录并检查配置。外部原始文件保持原位置。

### 原生GUI批量配置

双击根目录 `run_gui.bat`，在Ra样本页点击“一键配置”，按 `.bmp`、`.dat`、全部图片、所选行或全部样本批量修改。勾选要改的字段后一次应用，支持一次撤销；可配置标注开关、字号、颜色选择器、位置与描边，也可批量修改已有计算参数。预设只负责填入选项，应用前可核对范围和行数。

保存项目后使用“样本配置”模式分析。GUI的“导出 / 另存为 → Excel 配置（含标注设置）”新建包含上述列的工作簿，保留停用行，便于继续用Excel编辑或交给 `--config`。Excel改完后需重新导入GUI；项目JSON、CSV及运行快照均保留标注设置。原有配置表无需替换，缺列继续兼容；下次运行 `fill_config.bat` 时，写前备份并追加缺少的标注列，原参数与用户工作表保留，其原有过期行处理规则不变。

BMP标注读取到的截图Ra及原单位；DAT标注本次处理后面的Sa（nm），四联图内的Oblique与独立图一致。开关只控制附加文字，不删除仪器字段或坐标；原始输入、数值计算和min/medoid选择不变。大字号会占用更多绘图区，预览使用示意值；图像样式需重新分析后更新，既有历史输出不自动重绘。目录扫描模式保持旧默认样式。

## 输出

```text
Ra/
  ra_config.xlsx             输入配置，只读使用
  fill_config.bat            导入新文件：BMP去噪关、DAT去噪开
  run.bat                 一键运行，无交互
  ra_results.xlsx            纯结果：粗糙度分析 / DAT分析
  out/
    bmp/                     BMP独立Oblique裁图
      min/
      medoid/
    dat/
      combined/              四联图1089×800
        min/
        medoid/
        data/                原高度/基线/最终矩阵NPZ，剖面CSV
      single/                独立Oblique图602×325
        min/
        medoid/
```

DAT四联图为 Surface Map、Oblique Plot、Surface Profile、Intensity Map。两类图使用同一处理矩阵，独立开关出图。min为区域内最终粗糙度最小的样本，medoid延续项目定义：距区域均值最近的样本；并列按表格顺序取第一张。BMP按截图Ra选择，DAT按本次最终Sa选择，互不混算。

结果工作簿仅存输出值和本次“已应用”设置；修改其中的设置显示不会影响下次计算。配置工作簿不会被分析过程重建或覆盖。用户自建结果工作表保留，未运行类型的结果页保留上次内容；本次完整运行两类时同时刷新。

`out/bmp/manifest.json` 和 `out/dat/manifest.json` 记录配置路径/SHA256、具体配置行、实际参数、原始文件SHA256、输出文件清单。只清理上次清单拥有且内容未被修改的过期文件，未知文件保留；覆盖未登记/已被修改的同名图前复制到backups。旧BMP图保存在out/bmp/legacy_日期。

## 命令行

在Ra目录执行：

```powershell
.\run.bat                         # 读取ra_config.xlsx，处理全部启用行
.\run.bat --config '另一份配置.xlsx'
.\run.bat --types dat             # 配置中只运行DAT，保留BMP结果
.\run.bat --no-plot               # 更新计算结果，不改PNG
.\run.bat --batch 3               # 配置每组仅处理表格顺序前3行
.\run.bat --out '独立结果目录'
```

导入入口默认扫描data，不做分析也不改结果；也可指定外部目录或另一份配置：

```powershell
.\fill_config.bat
.\fill_config.bat --dir '外部数据目录'
.\fill_config.bat --dir '外部数据目录' --config '另一份配置.xlsx'
```

已有配置中明确设置的DAT去噪0会保留；要处理这些旧行，请在Excel中改为1。反复导入同一目录且配置无变化时不会产生重复行或重写配置。默认入口会移除当前data之外的旧配置行；显式传入`--dir`则追加且不自动清理旧行。不同目录同类型同名文件自动补充输出名后缀，源文件不移动、不改名。

便携解释器位于上一级python。缺配置时可首次初始化（已有配置绝不覆盖）：

```powershell
& '..\python\python.exe' '.\extract_ra.py' --init-config
```

首次初始化登记data文件，并一次性迁移旧ra_results.xlsx中的DAT参数。如果要创建另一份配置，使用 `--init-config --config '新的配置.xlsx'`。正常运行不读取结果里的参数，也不自动改配置。

首次初始化的新文件同样按BMP去噪0、DAT去噪1写入；旧DAT逐文件明确设置优先于新默认值。

为兼容临时扫描，保留 `--dir '输入目录'`，此模式与 `--config` 互斥，使用默认去噪关闭、高通关闭；**需要使用Excel设置时直接运行默认入口或--config，不要加--dir。**

`--no-plot` 保留PNG及它们对应的矩阵，新增计算另存combined/data_no_plot和analysis_no_plot.json；绘图manifest仍对应上次绘图。BMP继续支持1917×1003截图，数值识别及602×325裁剪位置沿用原实现。

## DAT方法与限制

1. 按DAT头部标定换算高度nm和横向µm；大端相位整数、强度uint16，无效点保留NaN。多帧强度取有效帧均值，按头部光强范围显示。
2. 有效点最小二乘去平面；关闭去噪仍去平面。保存原始高度、去平面高度和最终高度；源DAT只读、不翻转、不删除异常值。
3. 去噪在本批共享条纹范围kx=1..5、ky=3.5..8周/视场内，用Hann窗定位、全有效网格拟合单个正余弦后减去，再同口径去平面。记录振幅、频率、固定频率空间交错块留出检查；边界/失败提示保留。检查不能证明噪声来源，也不是无偏交叉验证。
4. 高斯高通采用镜像边界、50%振幅截止；自然样条采用行列可分离二阶差分惩罚、自然端部。样条缺测点仅为求解临时填0，最后恢复原掩膜，附近可能有偏差。两种均未核验与原生Gauss Spline等价；80µm超过本批约70.6×53µm视场，边界影响明显。
5. 中间行剖面不作平均。界面Ra/rms/PV分别显示面参数Sa/Sq/Sz；剖面为线参数、µm。颜色仅按0.5%/99.5%分位点饱和显示，不裁剪计算高度。静态边框和字形来自原界面，资源中的原测量纹理与数值已清除。

去噪是待独立重复测量验证的候选，不能仅凭Sa下降认定还原真实表面。此处为原界面风格重建，不是MetroPro原生渲染器，不保证逐像素一致。条纹频率范围专用于本批，其他扫描条件需重新检查。

## 代码与依赖

`extract_ra.py`保留截图识别和结果格式；`ra_config.py`读取/初始化配置；`ra_workflow.py`调度；`zygo_dat.py`计算；`zygo_render.py`及`zygo_style_assets.npz`绘图。依赖复用 `..\python` 已有numpy / Pillow / openpyxl，不新增安装、不创建环境。BAT为GBK+CRLF，源码UTF-8。
